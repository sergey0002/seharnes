## Суть

Legacy-экспорт задачи из Bitbucket. Выключен, заменен `jira-task` после перехода трекера на Jira.

---


## Когда вызывать

Когда брать сервер и в каком порядке: правило `.cursor/rules/mcp/bitbucket-task.mdc`, раздел `Когда`. Здесь фиксируется только эксплуатационное условие: сервер берут, когда локальный файл или тест не дают ответ дешевле.

## Правила использования

1. В задачах не использовать.
2. Экспорт задачи: `jira-task`.
3. Каталог `.doc/.bitbucket/` остается как исторический артефакт.

## Установка и перенос

- Установка: legacy `.doc/.bitbucket/server.php` в контейнере; отдельный пакет не нужен.
- Перенос: не переносить по умолчанию; при возврате трекера скопировать `.doc/.bitbucket` и заполнить конфиг.
- Проверка: `node .agents/skills/harness-router/children/mcp-audit/scripts/test-mcp-servers.mjs --only=bitbucket-task` после включения.

## Несколько проектов

- Один контейнер и один конфиг на проект; ключи Bitbucket не общие.
- Сервер stdio работает внутри контейнера проекта.
- Для задач использовать jira-task.
