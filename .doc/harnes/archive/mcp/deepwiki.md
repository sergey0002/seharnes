## Суть

Резервный источник внешней документации по репозиториям GitHub. Выключен, потому что основной источник это context7.

---


## Когда вызывать

Когда брать сервер и в каком порядке: правило `.cursor/rules/mcp/deepwiki.mdc`, раздел `Когда`. Здесь фиксируется только эксплуатационное условие: сервер берут, когда локальный файл или тест не дают ответ дешевле.

- Установка: `npx -y mcp-deepwiki@latest`; версия не закреплена, поэтому сервер отключен.

- Проверка: `node .agents/skills/harness-router/children/mcp-audit/scripts/test-mcp-servers.mjs --only=deepwiki` после включения.
