По packages/codemode/codemode.md из репозитория Kilo: через CodeMode идут только MCP-инструменты (они регистрируются как deferred). Прямые Core-инструменты остаются прямыми.
Твои Grep и Чтение на скрине это встроенные инструменты, не MCP. Их execute не покрывает. Поэтому модель физически не может загнать их в code_mode пачку.
Флаг experimental.batch_tool: true (~/.config/kilo/kilo.jsonc:519-524) только разрешает модели слать несколько вызовов в одном блоке. Заставить ее это делать он не может. В проблемной сессии модель слала по одному с паузами 20-300 секунд между вызовами.
Что реально пакуется через code_mode у тебя: serena.*, sourcegraph.*, playwright.*, то есть MCP. Встроенные grep/read/bash/glob идут мимо.
