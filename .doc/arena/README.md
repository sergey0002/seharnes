## Суть

Рабочая область для **исследования продукта** и согласования планов. Это не часть
харнеса: сюда складываются md-документы, найденные факты, исследования и находки по
продукту, а готовые к реализации планы — в `plans/`. Код в этом каталоге не правится;
код меняется только по **согласованным** планам из `plans/`.

> **AI:** читай этот файл, чтобы понять раскладку `.doc/arena/`. Исследования читай по
> задаче, планы — только перед реализацией. Не сканировать всё подряд.

---

## Навигация

### Исследования и находки
[`research/`](./research/) — здесь кладутся md-документы по результатам исследования
продукта: факты о коде, архитектуре, поведении, найденные проблемы и решения, аудиты.

### Планы
Планы готовятся **только по прямой команде и согласованию**. Папка `plans/` пока не
создана — план создаётся после явного согласования, и только согласованный план
служит основанием для правки кода.

---

## Правила

- Код не правится пока не будет **согласован** план.
- Планы не создаются без прямой команды и согласования.
- Исследования, находки и аудиты — это документация, по правилам
  [doc_rules](../harnes/doc_rules.md): один документ — одна тема, ссылки вместо
  копирования, конкретные пути и имена.
- Не использовать `[[wikilinks]]` и абсолютные пути, только md-ссылки.
