# send-to-git

Назначение.
Отправить правки задачи в git без случайного захвата лишних файлов и без push по
умолчанию.

Как работает.
Показывает состояние рабочей копии и список файлов задачи, предупреждает о
посторонних изменениях, готовит текст коммита и команды. Выполняет коммит и push
только после явного подтверждения, причем push требует отдельной просьбы.

Что нужно.
Список файлов задачи, чистая или понятная рабочая копия и настроенный git.

Чего не делает.
Не делает push сам по себе, не коммитит локальную настройку агента и не
захватывает чужие изменения.
