# yadisk-screenshot

Назначение.
Забрать скриншот или файл с публичной ссылки Яндекс.Диска в контекст работы, не
прося пользователя скачивать вручную.

Как работает.
Скачивает файл в локальную папку, имя строит из хеша ссылки, поэтому повторный
запуск берет готовый файл из кеша без обращения к сети. Печатает путь к файлу,
который можно сразу открыть.

Что нужно.
Публичная ссылка Яндекс.Диска и доступ к сети при первом скачивании.

Чего не делает.
Не работает с приватными ссылками, не хранит файлы в репозитории и не заменяет
просмотр изображения человеком.
