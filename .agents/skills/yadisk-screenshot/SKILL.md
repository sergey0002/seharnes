# Yandex.Disk Screenshot Fetcher

Когда пользователь присылает публичную ссылку на Яндекс.Диск с картинкой
(обычно скриншот) — НЕ открывай браузер и НЕ проси пользователя скачать вручную.
Запусти PS1-скрипт и приложи скачанный файл к контексту.

**Кеш:** имя файла = `yadisk_<sha256(url)[0..11]>.<ext>`. Если файл уже есть в
`imd/` — скрипт сразу возвращает путь без сетевых запросов. Чтобы перекачать
заведомо — передай `-Force`.

## Триггеры активации

- Сообщение содержит ссылку `https://disk.yandex.ru/i/...`, `https://disk.yandex.ru/d/...`,
  `https://yadi.sk/i/...`
- Пользователь пишет: «загрузи скрин с яндекса», «скачай картинку с яндекс диска»,
  «fetch yandex screenshot», «вот скрин на диске»
- В контексте упоминается `.doc/skil_data/yadisk-screenshot/`

## Скрипт

```powershell
powershell -NoProfile -ExecutionPolicy Bypass `
  -File .cursor/skills/yadisk-screenshot/scripts/yadisk-fetch.ps1 `
  -Url "<URL>"
```

Параметры:

| Параметр      | По умолчанию              | Описание |
|---------------|---------------------------|----------|
| `-Url`        | **обязательный**          | Публичная ссылка Яндекс.Диска |
| `-OutputDir`  | `.../mcpyandexscreen/imd` | Куда сохранять |
| `-NamePrefix` | `yadisk`                  | Префикс имени файла (итог: `<prefix>_<hash>.<ext>`) |
| `-Force`      | —                         | Перекачать, даже если файл с этим хешем уже есть |
| `-Quiet`      | —                         | Подавить статус, только путь |

Скрипт печатает **абсолютный путь** к скачанному (или уже существующему) файлу
в stdout (последняя строка вывода).

## Workflow

```
YadiskScreenshot:
- [ ] 1. Извлечь ссылку из сообщения пользователя
- [ ] 2. Запустить yadisk-fetch.ps1 -Url <URL>
- [ ] 3. Извлечь путь к файлу из последней строки stdout
- [ ] 4. Приложить файл к контексту (Read tool / описание)
- [ ] 5. Кратко отчитаться пользователю
```

### Шаг 1 — Извлечение ссылки

Из сообщения вида:

> вот скрин: https://disk.yandex.ru/i/HUpAFmr_sBwddQ что с этим делать?

извлеки URL целиком (без хвостовых знаков препинания). Если ссылок несколько —
обработай каждую.

### Шаг 2 — Запуск скрипта

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .cursor/skills/yadisk-screenshot/scripts/yadisk-fetch.ps1 -Url "https://disk.yandex.ru/i/HUpAFmr_sBwddQ"
```

**Exit codes:**

| Код | Значение | Действие |
|-----|----------|----------|
| 0   | Успех (в т.ч. cache hit) | Идём дальше |
| 1   | API не вернул `href` | Проверить что ссылка публичная; сообщить пользователю |
| 2   | Не удалось скачать   | Проблема сети/прав; сообщить пользователю |
| 3   | Неверный URL         | Перепроверить извлечённую ссылку |

### Шаг 3 — Захват пути

Путь — это **последняя непустая строка stdout** (или единственная строка при `-Quiet`).
Пример:

```
C:\projects\copytrust\testdeploydocker\.doc\.mcpyandexscreen\imd\yadisk_20260526_190608_a1b2c3.png
```

### Шаг 4 — Использование файла

После скачивания файл лежит локально, и его можно:
- Прочитать через инструмент Read (для image-файлов агент увидит содержимое)
- Сослаться по абсолютному пути в дальнейшем диалоге
- Скопировать/обработать через дополнительные команды

### Шаг 5 — Отчёт пользователю

```
✓ Скриншот с Яндекс.Диска
  Файл: .doc/skil_data/yadisk-screenshot/imd/yadisk_5ed9f9ce1c73.png
  Размер: 79 KB
  Источник: новое скачивание | из кеша
  [при необходимости: что на скриншоте — после прочтения]
```

Если строка статуса содержит `Уже скачано ранее:` — указать что использован кеш.

## Ограничения

- Ссылка должна быть **публичной** (доступной без авторизации).
- Не предлагать пользователю скачивать вручную, если можно вызвать скрипт.
- Папка `.doc/` целиком **не коммитится в git** — это локальная техническая
  директория разработчика. Файлы в `imd/` живут только локально.
- На Windows скрипт работает из коробки (PowerShell 5+). На других системах
  потребуется `pwsh` (PowerShell Core) или адаптация.

## Зависимости

- PowerShell 5+ в PATH (Windows — есть из коробки).
- Доступ в интернет к `cloud-api.yandex.net` и `downloader.disk.yandex.ru`.
- Файл `.cursor/skills/yadisk-screenshot/scripts/yadisk-fetch.ps1` (под контролем версий).

## Пример полного цикла

Пользователь:
> разбери что на этом скрине https://disk.yandex.ru/i/HUpAFmr_sBwddQ

Агент:
1. Запускает `yadisk-fetch.ps1 -Url "https://disk.yandex.ru/i/HUpAFmr_sBwddQ"`.
2. Получает путь `...\imd\yadisk_5ed9f9ce1c73.png`.
3. Читает изображение через Read.
4. Отвечает пользователю с разбором содержимого.

При повторном вопросе по той же ссылке в другом диалоге — скрипт мгновенно
вернёт тот же путь из кеша, без сетевых запросов.
