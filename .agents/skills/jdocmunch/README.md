# Jdocmunch MCP

Finds project documentation sections and retrieves their text, context and outline.
The repository handle selects the workspace documentation index.

Search uses a corpus filter for architecture, harness, tasks or the local panel.
Section identifiers come from search results or document outlines.
Freshness checks distinguish missing content from a stale index.

Cross-project groups are excluded from project searches.
Known skill document paths remain readable outside the indexed corpus after discovery.
Empty search results never authorize index updates, deletion or group changes.
The bundled server document preserves benchmarks, limitations and migration history.
