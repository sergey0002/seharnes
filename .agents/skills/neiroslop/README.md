# neiroslop

Назначение.
Убирает нейрослоп и канцелярит из русского текста и пишет с нуля простым разговорным
языком. Работает с отчётами к задачам, описаниями PR, письмами, постами и документацией.

Как работает.
Сначала определяет жанр и регистр по матрице, затем проверяет провенанс и структуру,
потом лексику. Каждая правка снимает оболочку и перестраивает фразу из тех же слов.
Факты, числа, даты, имена и оговорки переносятся без искажений. Новые факты, оценки и
детали не дописываются: чего нет в исходнике, то не появляется в тексте.
Порог срабатывания кластерный: три и более маркера в одном абзаце. Одиночный маркер
только помечается.

Что нужно.
Текст или файл на русском. Источник (бриф, заметки, diff, лог) нужен для проверки
провенанса и факт-замка. Жанр и читатель задаются запросом либо определяются по матрице.

Чего не делает.
Не обходит детекторы и антиплагиат, не вставляет опечатки и не подготавливает текст
под внешний AI-детектор. Не правит код, таблицы, URL, команды и юридические документы.
Не переписывает чужой текст без явной просьбы. Не меняет факты ради гладкости.
