# CodeGraph

Правило: [codegraph](../../../.cursor/rules/mcp/codegraph.mdc).
Подробности: [документ сервера](docs/mcp/codegraph.md).
В проекте маршрут по коду: CBM -> codegraph -> Serena. Результат графа закрывает
только реально возвращённый актуальный исходник. Для подготовки плана и правки
нужен весь затрагиваемый файл: если ответ содержит только символы, дочитать файл.
Полный актуальный файл из ответа инструмента повторно читать не требуется.

## Когда применять

- Нужен контекст по задаче до чтения файлов.
- Нужно найти символ, файл, вызывающих или blast radius по PHP, JS или Vue.
- Нужно понять, какие тесты затронуты изменениями.
- Нужно открыть локальный граф в браузере.
- Нужен один плотный ответ исходником и связями вместо grep и чтения файлов.

## Вход

- Текст задачи или вопроса.
- Список измененных файлов, если считается влияние.
- Точные имена классов и методов, если они известны.

## Шаги

1. Проверить индекс.

```bash
codegraph status --json
```

Если `.codegraph/` нет, сказать об этом и не создавать индекс без разрешения.

2. Собрать контекст задачи.

```bash
codegraph context "<задача>" --max-nodes 15 --no-code
```

`--no-code` дает структуру без исходников. Для полного JSON использовать
`--format json`. Для точного вопроса словами взять `explore`:

```bash
codegraph explore "<вопрос>" --max-files 6
```

Для общих слов (`order`, `status`, `controller`) добавлять имена классов.

3. Уточнить символ и связи.

```bash
codegraph query "<имя>" --limit 10
codegraph node "<Class::method>"
codegraph callers "<symbol>" --limit 20
codegraph impact "<symbol>" --depth 2
```

Для одноименных символов в PHP и JS добавлять файл через `--file`.

4. Подобрать тесты.

```bash
git diff --name-only | codegraph affected --stdin --quiet
```

Это подсказка, а не точный селектор: в этом репозитории общий `TestHelper`
связывает много тестов. Основной выбор тестов остается у `test-task`.

5. Открыть просмотрщик.

```bash
CODEGRAPH_UI=1 codegraph ui --read-only --no-open --port 4747
```

Запускать по запросу пользователя через средство фоновых процессов текущей среды.
Команда печатает URL, не открывает браузер и слушает только `127.0.0.1`.
При занятом порте выбрать свободный. Проектная обёртка
`bash .agents/skills/codegraph/scripts/codegraph-ui.sh` добавляет автоматический выбор порта;
её `--open` открывает браузер, `--port N` фиксирует порт.

6. Если codegraph не покрывает случай, перейти к другому инструменту.

- Точные qualified name и `trace_path`: CBM.
- Сообщества, `god_nodes`, `shortest_path`: в codegraph нет, для связей брать CBM
  `trace_path`; legacy graphify не используется.
- Документация `.doc/`: jdocmunch.
- `.tpl`, Markdown и JS-функции вида `Order.MakeReestr = function`: `rg` или чтение файла.

## Выход

- Список файлов и символов с строками.
- Вызывающие и blast radius, если запрашивались.
- Затронутые тесты с пометкой, что список широкий.
- URL просмотрщика, если он запускался.
- Явное указание, что не покрыто графом.

## Ограничения

- Граф построен tree-sitter, это приближение, а не компилятор. Для полного списка
  вызывающих при переименовании или смене сигнатуры проверять `rg`, codegraph дает
  ориентацию и предварительный рейтинг.
- `codegraph_callers` может недосчитать тестовых вызывающих. Для влияния брать CBM
  `trace_path` с `include_tests` или проверять `rg`.
- Аннотации тестов в `explore` могут быть ложноположительными, число тестов
  проверять `rg`.
- После правки файла watcher отстает на 1-2 секунды. При сомнении читать
  актуальный файл напрямую; `codegraph sync` меняет индекс и требует разрешения.
- Перегруженные имена (`load`, `run`, `execute`) искать через `codegraph node`
  с конкретным символом и файлом, а не через общий `callers`.
- `codegraph context` в 1.6.2 есть только в CLI. MCP по умолчанию отдает один
  `explore`, остальные инструменты включаются через `CODEGRAPH_MCP_TOOLS`.
- MCP-инструменты появляются после перезапуска клиента. CLI работает сразу. Если
  после перезапуска инструментов нет, проверить PATH и абсолютный путь к `codegraph`.
- Markdown и `.tpl` не индексируются.
- JS-присваивания вида `Order.MakeReestr = function` не извлекаются, файл читается
  напрямую.
- `codegraph affected` не является точным селектором тестов.
- Просмотрщик в версии 1.6.2 скрыт за `CODEGRAPH_UI=1`.
- Один демон на проект, около 200-280 МБ RSS, простой завершает его через 5 минут.
- Не индексировать чужие проекты без разрешения.
