# codegraph

Назначение.
Дает агенту быстрый доступ к локальному графу кода: контекст задачи, символы,
вызывающие, blast radius, затронутые тесты и браузерный просмотрщик.

Как работает.
Проверяет индекс, собирает контекст командой `codegraph context`, уточняет символы
через `query`, `node`, `callers` и `impact`, подбирает тесты через
`codegraph affected` и при необходимости поднимает локальный просмотрщик. Для
вопросов словами использует `codegraph explore` с точными именами и небольшим
числом файлов. В проекте идёт после CBM; сниппет не заменяет весь файл при подготовке
плана и правке. Просмотрщик запускается CLI-командой без проектной обёртки.

Что нужно.
Установленный CLI `codegraph`, каталог `.codegraph/` в корне проекта и свободный
локальный порт для просмотрщика.

Чего не делает.
Не индексирует документацию и Smarty-шаблоны, не заменяет CBM для qualified name
и `trace_path`, не дает сообществ, god nodes и shortest path, не выбирает тесты
задачи вместо `test-task`.
