## Суть

Security-сканы кода: AST, список языков и схема правил. Включается при рисковых изменениях и перед коммитом критичных правок.

---


## Когда вызывать

Когда брать сервер и в каком порядке: правило `.cursor/rules/mcp/semgrep.mdc`, раздел `Когда`. Здесь фиксируется только эксплуатационное условие: сервер берут, когда локальный файл или тест не дают ответ дешевле.

## Конфигурация

| Параметр | Значение |
|---|---|
| Тип | stdio |
| Запуск | `uvx semgrep mcp` |

## Текущие значения

| Параметр | Значение |
|---|---|
| Статус | включен |

Секреты не печатаются, только имена переменных. Полная конфигурация в разделе `Конфигурация`.

## Инструменты

| Инструмент | Параметры | Зачем |
|---|---|---|
| `semgrep_scan` | `code_files`: абсолютные пути | локальный скан правилами Semgrep |
| `semgrep_scan_with_custom_rule` | `code_files`, `rule` (YAML) | скан своим правилом |
| `semgrep_findings` | `issue_type`, `repos`, `status`, `severities`, `limit` | находки платформы, нужен токен |
| `get_abstract_syntax_tree` | `code`, `language` | AST |
| `semgrep_rule_schema` | - | схема правила |
| `get_supported_languages` | - | поддерживаемые языки |
| `semgrep_scan_supply_chain` | - | проверка зависимостей |
| `semgrep_scan_remote` | - | удаленный скан, если сервер hosted |
| `semgrep_whoami` | - | аккаунт и токен |

---

## Правила использования

1. Запускать при изменениях, связанных с security, SQL, XSS и доступом.
2. Перед коммитом критичных правок.
3. Результаты проверять вручную, ложные срабатывания возможны.

---

## Установка и перенос

- Установка: `uvx semgrep mcp`; нужен `uv` и Python, пакет semgrep скачивается в кеш uv.
- Перенос: скопировать запись `semgrep`; версию пакета закрепить, сейчас она не закреплена.
- Для `semgrep_findings` нужен токен Semgrep AppSec; локальный `semgrep_scan` работает без него.
- Проверка: `node .agents/skills/harness-router/children/mcp-audit/scripts/test-mcp-servers.mjs --only=semgrep`.

## Несколько проектов

- stdio-сервер запускается на каждый проект отдельно; сканирует только переданные пути.
- Кеш uv общий, результаты сканов не сохраняются между проектами.
- Пути передавать абсолютные и внутри корня проекта.
