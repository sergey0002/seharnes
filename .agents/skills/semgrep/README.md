# Semgrep MCP

Scans selected workspace files for security risks with local Semgrep rules.
Custom rules and syntax-tree inspection support investigation of specific matches.

Absolute paths restrict scans to the current repository.
Findings are reviewed against source and separated from false positives.
Reports identify the rule, location, risk and scan coverage.

Platform findings describe prior runs rather than the current local source.
External code transmission requires explicit authorization.
The bundled server document preserves installation details and known limitations.
