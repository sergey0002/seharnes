# platform-logs

Назначение.
Читает логи площадки CopyTrust по номеру заказа, UIN, e-mail клиента или taskId
и собирает таймлайн событий.

Как работает.
Открывает админский DbLog на тестовом стенде, загружает нужные страницы по 100
строк, фильтрует их по идентификатору на клиенте и сортирует по номеру записи.
Скил описывает параметры запроса как API, поэтому поиск идёт и в браузере, и в
консоли.

Что нужно.
Вход в админку стенда, номер заказа или другой идентификатор и знание примерного
периода события. По умолчанию используется стенд d8.

Чего не делает.
Не меняет данные, не ищет по тексту на сервере и не заменяет разбор кода.
Не доказывает отсутствие события, если логи старше срока хранения.
