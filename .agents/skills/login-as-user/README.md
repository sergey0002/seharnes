# login-as-user

Назначение.
Зайти в интерфейс под конкретным клиентом, чтобы воспроизвести его баг или
проверить сценарий под нужной ролью.

Как работает.
Использует админский механизм входа под клиентом по идентификатору, а не пароль
клиента. Подставляет нужную сессию в браузер, чтобы проверка шла от лица
клиента.

Что нужно.
Доступ администратора, dev-стенд и идентификатор клиента из задачи.

Чего не делает.
Не работает на проде, не хранит пароли клиентов и не заменяет проверку прав
доступа.
