# task-intake

Назначение.
Завести задачу в систему и довести ее документацию до текущих правил, когда
папка задачи пустая, диф устарел или оформление старое.

Как работает.
Оркестрирует уже существующие инструменты: описание и данные трекера, диф по
коммитам, бизнес-правила, документацию задачи и индекс задач. Своих артефактов
не пишет, только вызывает нужные шаги в правильном порядке.

Что нужно.
Доступ к трекеру, git, скриптам документации и бизнес-анализа, а также номер
задачи.

Чего не делает.
Не дублирует логику других скилов и не создает собственные форматы документов.
