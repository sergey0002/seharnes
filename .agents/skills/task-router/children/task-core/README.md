# task-core

Назначение.
Управляет источниками задач и адаптерами трекеров: Jira, Kaiten и аналитикой.

Как работает.
Родитель выбирает дочерний адаптер, хранит общие правила источников и не дублирует код трекеров.

Что нужно.
Описание трекера, доступы в env и формат идентификатора задачи.

Чего не делает.
Не пишет отчеты в трекер вместо `task-report`, не хранит секреты и не добавляет адаптер без кода.
