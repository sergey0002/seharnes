# Источники задач

| Источник | Идентификатор | Владелец |
|---|---|---|
| Jira | числовой номер или `CT-N` | `children/jira` |
| Локальная задача | `0_N` | `task-intake` / `task-doc` |
| Kaiten | внешний id | `children/kaiten`, docs-only |

Идентификатор задачи всегда номер. Заголовок и slug не являются идентификатором.
