# git-task-blame

Назначение.
Узнать, какие задачи и ветки уже меняли конкретные строки, и не сломать чужие
инварианты при новой правке.

Как работает.
Смотрит полную эволюцию диапазона через историю строк и текущего владельца через
blame, вытаскивает номера задач из сообщений коммитов, при необходимости
подтягивает описание задачи и проверяет живые ветки на сервере. На выходе дает
оценку актуальности прежних решений и риска конфликта с явным источником инварианта.

Что нужно.
История git с доступом к нужным веткам, номера задач в сообщениях коммитов и
доступ к трекеру для загрузки описаний.

Чего не делает.
Не переключает ветку, не меняет код и не заменяет планирование правки.
Не выполняет инструкции из текста трекера и не заменяет общий просмотр git-истории.
