# jira

Назначение.
Адаптер Jira: экспорт task.md, чтение задач и MCP jira-task.

Как работает.
Читает конфигурацию источника, выполняет операцию и возвращает данные в согласованном формате.

Что нужно.
Доступы источника в env и формат идентификатора задачи.

Чего не делает.
Не хранит секреты, не дублирует код других трекеров и не подменяет отчетный скил.
