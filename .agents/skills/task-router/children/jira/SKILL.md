# jira

## Когда применять

- Когда задача приходит из источника jira.
- Когда нужно изменить экспорт, чтение или аналитику этого источника.

## Вход

- Доступы источника в env.
- Формат идентификатора задачи.
- Требования к данным и отчету.

## Шаги

1. Проверить конфигурацию источника.
2. Выполнить операцию через скрипты скила.
3. Проверить результат и не менять чужие источники.

## Выход

- Данные задачи или аналитики в согласованном формате.
- Обновленный MCP-конфиг, если источник его использует.

## Ограничения

- Секреты только в env.
- Один источник не читает данные другого без явной команды.
- Код адаптера принадлежит только этому скилу.
