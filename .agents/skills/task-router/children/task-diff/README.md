# task-diff

Назначение.
Собрать диф именно по задаче, чтобы видеть только ее правки, а не весь рабочий
каталог.

Как работает.
Берет коммиты с номером задачи в сообщении и добавляет незакоммиченные правки.
Раскладывает результат в полный диф и компактный список файлов. Для другой среды
есть тонкая обертка без собственной логики.

Что нужно.
История git с сообщениями коммитов, рабочий каталог и номер задачи.

Чего не делает.
Не коммитит, не фильтрует чужие правки по смыслу и не заменяет ревью кода.
