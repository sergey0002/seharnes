## Суть
Скрипт формирует артефакты изменений по задаче в каталоге `.doc/tasks/{N}/`: сводный diff изменений `diff.md` и структурированный список затронутых файлов `diff.files.md`. Он автоматически определяет точку ветвления от базового релиза, фильтрует коммиты задачи и сохраняет результат в кодировке UTF-8.

## Когда запускать
Скрипт вызывается при подготовке к реализации задачи, после внесения изменений в код перед формированием отчета или коммита, а также при переходе к задаче через `gototask`.

## Аргументы
| Аргумент | Алиас | Тип | Обязателен | По умолчанию | Что делает |
|---|---|---|---|---|---|
| `-TaskNumber` | нет | string | да | нет | номер задачи (например, 2070) |
| `-Action` | нет | string | нет | "generate" | режим работы: generate для создания файлов или inspect для вывода информации |
| `-RepoPath` | нет | string | нет | "" | путь к корню git-репозитория |
| `-ConfigPath` | нет | string | нет | "" | путь к файлу конфигурации gototask |
| `-ReleaseBranch` | нет | string | нет | "" | имя базовой релизной ветки |
| `-TaskBranch` | нет | string | нет | "" | точное имя ветки задачи |
| `-ForkCommit` | нет | string | нет | "" | хеш коммита точки ветвления |
| `-UseRemoteTip` | нет | switch | нет | выключен | использовать последний коммит из удаленного репозитория |
| `-StrictMatch` | нет | switch | нет | выключен | строгое сопоставление имени ветки и коммитов |
| `-SkipFetch` | нет | switch | нет | выключен | пропускать git fetch при проверке |
| `-Mode` | нет | string | нет | "full" | режим сравнения: full (полный diff) или ahead (только опережающие коммиты) |
| `-AheadOnly` | нет | switch | нет | выключен | учитывать только коммиты, отсутствующие в релизной ветке |
| `-NoReleaseBase` | нет | switch | нет | выключен | не использовать релизную ветку в качестве базы |

## Коды выхода
| Код | Значение | Действие вызывающего |
|---|---|---|
| 0 | diff успешно сформирован или инспектирован | использовать файлы diff.md и diff.files.md |
| 1 | ошибка git-репозитория, ветка не найдена или прервана генерация | проверить наличие ветки и коммитов задачи |

## Что читает и что пишет
Читает историю коммитов, ссылки и патчи git-репозитория. Пишет файлы `.doc/tasks/{TaskNumber}/diff.md` и `.doc/tasks/{TaskNumber}/diff.files.md`.

## Побочные эффекты
Создает и перезаписывает файлы `diff.md` и `diff.files.md` в каталоге задачи. При отсутствии `-SkipFetch` выполняет чтение удаленных ссылок git.

## Окружение и зависимости
Требуется PowerShell (Windows PowerShell 5.1+ или PowerShell Core 7+) и установленный git CLI. Запускается в контексте репозитория.

## Примеры
```powershell
powershell -File .agents/skills/task-router/children/task-diff/scripts/task-diff.ps1 -TaskNumber 2070
powershell -File .agents/skills/task-router/children/task-diff/scripts/task-diff.ps1 -TaskNumber 2070 -Action inspect
powershell -File .agents/skills/task-router/children/task-diff/scripts/task-diff.ps1 -TaskNumber 2070 -Mode ahead -SkipFetch
```

## Ограничения
Коммиты задачи идентифицируются по наличию номера задачи в заголовке или по истории ветки задачи. Коммиты без номера задачи в сообщении могут не войти в full diff при отсутствии явного указания ветки.

## Связи
Вызывается навыками `task-router`, `gototask`, `prepare-plan`. Сформированные файлы используются для контекста задачи и генерации отчетов.
