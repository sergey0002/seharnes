# audit-plan

Назначение.
Проверяет план реализации и сразу исправляет его. На выходе один plan.md,
готовый к исполнению, с видимыми метками аудиторских правок.

Как работает.
Назначает номер прохода и читает план с журналом. Пересобирает доказательства:
радиус, связанные задачи, историю строк, чтение файлов. Проходит критерии C1-C6 и
вносит правки прямо в план, помечая каждую номером прохода и датой. Обновляет
журнал и выставляет вердикт pass, fail или blocked.

Что нужно.
Текущий plan.md, свежий task.md, доступ к графу кода и истории git, критерии
аудита и отдельный аудитор, который не писал этот план.

Чего не делает.
Не создает отдельный файл аудита, не считает хеши плана и источников. Не правит
продуктовый код, тесты и шаблоны. Не решает за пользователя, когда нужна смена
рамок задачи.
