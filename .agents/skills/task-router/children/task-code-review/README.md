# task-code-review

Назначение.
Проверить, что диф задачи содержит только ее правки, и не тащить в ревью чужой
legacy в тех же файлах.

Как работает.
Ограничивает область файлами из диффа задачи и сверяет каждый фрагмент с
коммитами задачи. Если фрагмент не принадлежит задаче, он помечается, а не
правится молча.

Что нужно.
Диф задачи по файлам и коммитам, сообщения коммитов с номером задачи и исходники
в текущем состоянии.

Чего не делает.
Не переписывает чужие изменения, не расширяет область задачи и не заменяет
обычное ревью кода.
