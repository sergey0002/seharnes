# gototask

Назначение.
Перейти на ветку задачи Jira по номеру и получить актуальное описание, чтобы
дальше работать в правильной ветке и с верным описанием задачи.

Как работает.
Обновляет описание задачи из Jira, ищет ветку на сервере, создает ее от релизной
или вливает релиз в существующую, переключает рабочую копию. Создание ветки,
слияние и откат локальных правок требуют явного подтверждения. После перехода
синхронизирует данные трекера и разбирает свежий комментарий.

Что нужно.
Доступ к Jira, git с настроенным сервером, релизная ветка и чистая или
подтвержденная рабочая копия.

Чего не делает.
Не делает push, не создает ветку без подтверждения и не отбрасывает локальные
правки молча.
