# reporting-router

Назначение.
Управляет отчетами по задачам: короткий отчет в трекер и HTML-отчет об изменениях. Применять по запросам отчет в трекер, HTML-отчет, task-report, task-change-report.

Как работает.
Родитель принимает запрос, выбирает дочерний скил по маршрутизации и загружает его.

Что нужно.
Корень проекта и описание дочерних скилов.

Чего не делает.
Не дублирует код детей и не хранит их данные.
