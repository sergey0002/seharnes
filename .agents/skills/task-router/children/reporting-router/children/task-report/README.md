# task-report

Назначение.
Написать комментарий в Jira, понятный без чтения кода и диффа.

Как работает.
Сохраняет порядок образца пользователя: прежняя логика, проблема с фактами из
логов, новая логика, исходы ошибок. Пишет естественными абзацами без обязательных
заголовков и формального вступления. Объясняет обмен данными между сайтом и
сервисами: кто отправляет запрос, на какой полный URL, что передает и чего ждет.
Использует названия объектов и статусов из задачи, различает заказ клиента и
задание внешнего сервиса. Файлы и источники данных добавляет по запросу о
реализации, без кода и имен функций. Отделяет подтвержденную проблему от гипотезы
о ее причине. Заканчивает строкой с релизом, вложения показывает отдельно.

Что нужно.
Описание задачи, итог работы, результаты проверок и при необходимости
скриншоты.

Чего не делает.
Не пересказывает дифф, не вставляет сырые логи и не отправляет комментарий без
подтверждения.
