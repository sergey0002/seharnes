# task-change-report

Назначение.
Объяснить изменения задачи отдельным HTML-отчетом: что поменялось в бизнес-логике,
где, зачем и чем проверено.

Как работает.
Собирает модель отчета по данным задачи, отделяет бизнес-смысл от технических
деталей, добавляет сценарии, связи модулей, диаграммы, тесты и риски. Схема и
генератор проверяют модель до вывода страницы.

Что нужно.
Данные задачи, диф, результаты проверок и подготовленный контекст отчета.

Чего не делает.
Не заменяет документацию задачи, не пишет текст комментария в трекер и не
доказывает корректность бизнес-выводов вместо человека.
