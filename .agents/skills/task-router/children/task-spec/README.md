# task-spec

Назначение.
Собрать требования из свободной переписки и превратить их в однозначный документ
задачи, который не допускает разных толкований.

Как работает.
Ведет черновик в каталоге данных проекта. Каждое замечание, сообщение и вложение
фиксирует отдельно и отвечает коротким подтверждением. По команде
"сформулируй задачу" исследует код и документацию, при необходимости делит
задачу на части и пишет документ с требованиями, критериями приемки и ссылками
на сохраненные скриншоты и файлы.

Что нужно.
Корень проекта. Для скриншотов по ссылке Яндекс.Диска нужен скил
yadisk-screenshot. Для исследования кода полезны граф кода и документация
проекта.

Чего не делает.
Не заводит задачу в трекере, не переключает ветку, не пишет план реализации,
не меняет код и не восстанавливает вложение, у которого нет файла или ссылки.
