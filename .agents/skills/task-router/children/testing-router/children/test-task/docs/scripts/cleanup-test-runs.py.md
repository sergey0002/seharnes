## Суть
Удаляет старые каталоги прогонов из `.doc/tasks/{N}/test-runs/`. Дату прогона скрипт читает из содержимого прогона, а не из mtime файлов. По умолчанию работает в режиме dry-run и только печатает кандидатов; удаление выполняется с `--apply`.

## Когда запускать
- когда прогоны задач накопились и старые доказательства больше не нужны;
- перед разбором места на диске в `.doc/tasks/`;
- по запросу «очисти старые тесты» или «удали старые прогоны».

## Аргументы
| Аргумент | Алиас | Тип | Обязателен | По умолчанию | Что делает |
|---|---|---|---|---|---|
| `--root DIR` | | string | нет | `.` | корень проекта |
| `--days N` | | integer | нет | `14` | хранить прогоны младше N дней |
| `--task N` | | string | нет | все задачи | ограничить одной задачей |
| `--include-files` | | flag | нет | | учитывать файлы верхнего уровня `test-runs/` |
| `--apply` | | flag | нет | dry-run | удалить найденные каталоги и файлы |
| `--ignore-reports` | | flag | нет | | не защищать прогоны, на которые ссылаются отчёты задач |
| `--json` | | flag | нет | | вывести отчёт в JSON |
| `--now YYYY-MM-DD` | | string | нет | сегодня | текущая дата для проверки и тестов |

## Коды выхода
| Код | Значение | Действие вызывающего |
|---|---|---|
| 0 | проверка или удаление прошли без ошибок | прочитать отчёт |
| 2 | нет `.doc/tasks` или неверные аргументы | исправить путь или аргумент |
| 3 | часть кандидатов не удалена | разобрать `errors` и повторить |

## Что читает и что пишет
**Читает:**
- `report.md` в каталоге прогона: frontmatter, затем первая дата в тексте;
- `verdict.json`, `manifest.json`, `history-entry.json`, `ac-source.json`: поля с датой, временем или именем прогона;
- имя каталога прогона как последний источник даты.

**Пишет:**
- без `--apply` ничего не пишет;
- с `--apply` удаляет каталоги `.doc/tasks/{N}/test-runs/*` и, при `--include-files`, файлы верхнего уровня `test-runs/`;
- печатает таблицу или JSON: `cutoff`, `candidates`, `removed`, `undated`, `errors`.

## Побочные эффекты
- `--apply` удаляет каталоги и файлы без корзины.
- Прогон, на который ссылается `doc.md`, `test.md`, `plan.md`, `task.json`, `diff.md` или `reports/` задачи, защищён и попадает в `protected`.
- Симлинки и пути за пределами `test-runs/` не удаляются.
- Каталог без даты в содержимом и в имени пропускается и попадает в `undated`.
- mtime не используется.

## Окружение и зависимости
Python 3.10 или новее, стандартная библиотека. Корень проекта определяется по `.git` или по паре `.doc` и `.agents`. Внешние пакеты и сеть не нужны.

## Примеры
```bash
# Показать кандидатов старше 14 дней
python3 .agents/skills/task-router/children/testing-router/children/test-task/scripts/cleanup-test-runs.py --days 14

# Удалить их
python3 .agents/skills/task-router/children/testing-router/children/test-task/scripts/cleanup-test-runs.py --days 14 --apply

# Только одна задача, машинный отчёт
python3 .agents/skills/task-router/children/testing-router/children/test-task/scripts/cleanup-test-runs.py --task 2070 --days 30 --json
```

## Ограничения
- Не удаляет каталоги без даты: `screens`, `screenshots`, `manual*` и подобные требуют ручного решения.
- По умолчанию защищает прогоны, на которые ссылаются отчёты и документы задачи. `--ignore-reports` снимает защиту.
- Дата из текста отчёта может быть датой события, а не запуска; приоритет отдан frontmatter и полям JSON.
