# test-task

Назначение.
Проверить реализованную задачу целиком: ее сценарии, соседние флоу и готовность
по гейтам.

Как работает.
Определяет задачу, собирает влияние по дифу и реестру флоу, проверяет наличие
теста и при отсутствии собирает его. Запускает браузерную проверку, пишет отчет
и сверяет результат с гейтами. Умеет режим одного этапа, когда проверяются
только его сценарии.
Соседние скрипты берёт из собственного каталога скила. Версию PHP приложения
проверяет отдельно от PHP раннера Codeception; зелёный Cest не заменяет общий вердикт.
Чистит прогоны старше 14 дней скриптом `cleanup-test-runs.py`: дата берётся из
содержимого прогона, по умолчанию это dry-run.

Что нужно.
Задача с дифом и матрицей покрытия, тестовые методы, стенд и доступ к роли.

Чего не делает.
Не поднимает стенд без разрешения, не гоняет весь набор вместо нужных методов и
не заменяет планирование или реализацию.
