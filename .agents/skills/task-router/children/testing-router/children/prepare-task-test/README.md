# prepare-task-test

Назначение.
Собрать браузерный тест задачи из уже готовых слоев, не изобретая селекторы и
шаги заново.

Как работает.
Комбинирует Page-объекты с селекторами, Step-объекты с бизнес-шагами и фрагменты
AcceptanceTester в один сценарий. Кладет тест и парную матрицу покрытия в папку
задачи. Новых путей к элементам не пишет.

Что нужно.
Готовые Page и Step-объекты, описание веток поведения и доступ к тестовому
окружению.

Чего не делает.
Не придумывает селекторы, не правит продуктовые шаблоны ради теста и не
запускает полный набор вместо точечного сценария.
