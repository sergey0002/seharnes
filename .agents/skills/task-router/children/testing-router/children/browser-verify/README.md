# browser-verify

Назначение.
Проверить реализованную задачу и соседние UI-флоу в браузере, получить
детерминированный результат без ручных кликов и подтвердить, что интерфейс и
данные ведут себя как ожидается.

Как работает.
Основной слой это Codeception Acceptance по группам. Он проходит сценарии в
видимом браузере, проверяет элементы страницы и состояние базы. Playwright
подключается только для веток, у которых нет метода в тесте. Результат прогона
сохраняется вместе со скриншотами и вердиктом.

Что нужно.
Поднятый стенд, доступ к нужной роли, запущенный драйвер браузера и готовые
тестовые методы или сценарии.

Чего не делает.
Не пишет новые тесты, не поднимает стенд без разрешения и не заменяет ручную
проверку спорных визуальных решений.
