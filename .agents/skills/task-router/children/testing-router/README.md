# testing-router

Назначение.
Управляет тестированием: тесты задачи, подготовка тестов, браузерная проверка. Применять по запросам тестирование, проверь задачу, подготовь тест, browser-verify, тесты.

Как работает.
Родитель принимает запрос, выбирает дочерний скил по маршрутизации и загружает его.

Что нужно.
Корень проекта и описание дочерних скилов.

Чего не делает.
Не дублирует код детей и не хранит их данные.
