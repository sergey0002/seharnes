# ponytail

Назначение.
Помогает выбрать минимальный полный патч: меньше нового кода, без лишних
абстракций и зависимостей, но без потери проверок, безопасности и обработки ошибок.

Как работает.
Сначала читает задачу и затронутый код, затем идёт по лестнице: нужно ли это,
есть ли уже в коде, умеет ли стандартная библиотека или платформа, есть ли
установленная зависимость, можно ли одной строкой, иначе минимум рабочего кода.
Новую рискованную логику закрывает проверкой. В ответе называет пропущенное и
остаточный риск.

Что нужно.
Текст задачи, исходники и правила проекта. Для ревью и аудита нужен диф или
каталог, который проверяется.

Чего не делает.
Не заменяет планирование, тестирование и проверку принадлежности правок задаче.
Не меняет код во время ревью и аудита. Не переносит команды и хуки конкретной
среды.
