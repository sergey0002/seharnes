# php-deps-mcp

## Шаги

1. Найди границы модуля через CBM и codegraph. Не запускай анализ всего
   репозитория вместо исследования конкретного компонента.
2. Для графа вызовов вызови `phpcallgraph_generate` с `sourcePath`,
   `outputFile`, `format` и `ignorePattern`. Пути относятся к текущему проекту.
3. Для зависимостей и нарушений слоев проверь существующий `phpda.xml`
   и вызови `phpda_analyze` с `configFile`.
4. Сохрани граф в рабочем каталоге проекта, укажи путь в результате.
5. Подтверди значимые связи через символы Serena и чтение вызывающего кода.

## Границы

- Генерация графа пишет артефакт. Не перезаписывай чужой файл результата.
- Не создавай и не меняй `phpda.xml` только ради запуска без задачи на настройку.
- Статический граф не доказывает runtime-поведение и разрешение DI-контейнера.
- При недоступном toolchain зафиксируй ограничение и используй доступный граф кода.
