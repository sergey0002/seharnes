# phpstan-mcp

## Шаги

1. Определи PHP-файлы текущей задачи и конфигурацию анализа проекта.
2. Для задачи вызови `phpstan_analyze` с `task` и `level`. Для проверки вне
   задачи передай узкий массив `paths` вместо номера.
3. Начни с принятого в проекте уровня 0. Повышай уровень точечно для
   затронутого кода, сохраняя различие между новыми и legacy-ошибками.
4. Проверь exit status и сообщения анализатора. Ошибка запуска toolchain
   не означает успешный анализ без замечаний.
5. Исправь ошибки своей правки и повтори анализ того же набора файлов.
   Отдельно укажи оставшиеся прежние ошибки и непройденные проверки поведения.

## Границы

- Не запускай весь проект без `task` или `paths`.
- Исключай vendor, кэш и сгенерированные файлы.
- Версия runtime PHP и целевой язык анализа различаются; не меняй `phpVersion`
   или окружение для подавления ошибок.
- PHPStan не заменяет сценарии задачи и браузерные проверки.
