# briefing-intake

Формализует сырую мысль пользователя в одобренную задачу и исследовательский
протокол до запуска поиска. Фиксирует цель, границы, критерии готовности и
замороженный бриф. Применяется когда пришла новая размытая задача, выбор,
сравнение, разработка стандарта или восстановление продукта.

Входит в пакет `exhaustive-research-decision-v6`. Вызывается родительским
скиллом по маршрутизации запроса. Инструкция: `SKILL.md`.
