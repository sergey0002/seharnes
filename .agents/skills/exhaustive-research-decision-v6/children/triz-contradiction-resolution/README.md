# triz-contradiction-resolution

Опциональный ТРИЗ-слой для неразрешимых противоречий, идеального конечного
результата, ресурсов и поиска неочевидных решений. Применяется когда обычное
сравнение упирается в конфликт требований. Не является обязательным гейтом.

Входит в пакет `exhaustive-research-decision-v6`. Вызывается родительским
скиллом по маршрутизации запроса. Инструкция: `SKILL.md`.
