# evidence-provenance

Ведёт канонический факт-слой: источники, claims, реестр методов,
противоречия и синтез. Применяется когда любой вывод, критерий, вес,
признак или исключение должен трассироваться по цепочке F/CL - S - M.

Входит в пакет `exhaustive-research-decision-v6`. Вызывается родительским
скиллом по маршрутизации запроса. Инструкция: `SKILL.md`.
