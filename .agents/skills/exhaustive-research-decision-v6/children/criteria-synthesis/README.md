# criteria-synthesis

Строит единый реестр критериев из четырёх источников и полную матрицу
признаков. Объединяет характеристики разных решений, дозаполняет пропуски
вторым проходом и отделяет синтетические проектные метрики от фактов.

Входит в пакет `exhaustive-research-decision-v6`. Вызывается родительским
скиллом по маршрутизации запроса. Инструкция: `SKILL.md`.
