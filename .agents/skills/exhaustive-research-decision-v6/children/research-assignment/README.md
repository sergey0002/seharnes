# research-assignment

Превращает вопросы, требования, критерии, оси покрытия и gaps в конкретные
исследовательские задания с владельцем, методом, выходным файлом и условием
остановки. Применяется после брифа и критериев, когда работу нужно раздать
субагентам.

Входит в пакет `exhaustive-research-decision-v6`. Вызывается родительским
скиллом по маршрутизации запроса. Инструкция: `SKILL.md`.
