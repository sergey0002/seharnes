# existing-solution-scouting

Ищет существующие решения с подтверждённым опытом успешного применения до
всякого изобретения нового подхода. Строит longlist, доказательства
внедрения, shortlist и reuse decision. Кандидатом может быть продукт, сервис,
стандарт, методика, процесс, железо или комбинация.

Входит в пакет `exhaustive-research-decision-v6`. Вызывается родительским
скиллом по маршрутизации запроса. Инструкция: `SKILL.md`.
