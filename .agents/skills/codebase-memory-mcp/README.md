# Codebase Memory MCP

Explores code structure, symbols, callers and diff impact in the workspace graph.
The server selects a repository through the project returned by list_projects.

The workflow checks index freshness and coverage before interpreting results.
Search returns qualified names for call tracing and source retrieval.
Diff analysis identifies affected code and candidate tests.

Documentation, live database schemas and source edits use their own tools.
These boundaries are also part of the skill's discovery description.
Index creation and deletion require approval. Cross-project queries are excluded.
The bundled server document preserves installation details and operational history.
