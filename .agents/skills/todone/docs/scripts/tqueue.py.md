## Суть
Точка входа для управления очередями: поиск, создание, регистрация, порядок и просмотр доски. Делегирует работу в `tdcore.queue_cli.QueueCli`.

## Когда запускать
При работе с очередями проекта: инициализация проекта (`tqueue init`), поиск очереди (`tqueue find`), создание очереди (`tqueue new`), просмотр списка/доски (`tqueue list`, `tqueue board`).

## Аргументы
Общие флаги: `--root` (каталог проекта), `--queue` (алиас очереди), `--json`, `--fields`, `--quiet`, `--limit`, `--by`.
Подкоманды: `find`, `new`, `list`, `board`, `init`, `register`, `order`, `settings`, `status`.
Каждая подкоманда имеет свои флаги (см. `tqueue <cmd> --help`).

## Коды выхода
- 0: успех
- 1: ошибка контроля/валидации (находки)
- 3: требуется человеческое вмешательство (ASK_USER)

## Что читает и что пишет
Читает: `<root>/.todone/queues.json` (реестр), `<queue>/.todone/` (индекс, настройки).
Пишет: при создании/регистрации очереди обновляет реестр и создает структуру очереди.

## Побочные эффекты
Создает каталоги и файлы очереди, обновляет реестр проектов.

## Окружение и зависимости
`TODONE_ROOT` (альтернатива `--root`). Требует Python 3.8+.

## Примеры
```bash
tqueue find
tqueue new main --type kanban
tqueue list --json
tqueue board main --limit 20
```

## Ограничения
Не управляет записями внутри очереди (для этого `ttask`). Не работает с удаленными очередями.
