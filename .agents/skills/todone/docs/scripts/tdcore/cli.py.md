## Суть

Общий контракт CLI очередей todone: разбор аргументов, печать результата, коды
возврата и отказ одной строкой. Три точки входа подключают только состав команд,
а разбор флагов и вывод живут здесь.

## Когда запускать

Через точки входа скила `todone`; напрямую не вызывается. Модуль задаёт общие
флаги и формат вывода для всех команд очередей.

## Аргументы

| Аргумент | Значение |
|---|---|
| `--root` | Корень проекта, где лежат очереди и реестр. |
| `--queue` | Имя очереди; по умолчанию очередь проекта. |
| `--json` | Печать JSON вместо строк. |
| `--fields` | Список полей вывода через запятую. |
| `--quiet` | Печатать только ошибки. |
| `--limit` | Ограничение числа объектов в выводе. |
| `--by` | Автор операции для журнала. |

## Коды выхода

| Код | Значение |
|---|---|
| 0 | Операция выполнена. |
| 1 | Найдены замечания или отказ команды. |
| 2 | Нужен ответ пользователя. |

## Что читает и что пишет

Читает файлы очередей и реестр через `queue.py`. Запись выполняют команды,
помеченные `mutating`; сам разбор аргументов ничего не пишет.

## Побочные эффекты

Нет: модуль только разбирает аргументы, печатает и возвращает код.

## Окружение и зависимости

Python 3, модули `schema`, `errors`, `queue` и `report` пакета `tdcore`.

## Примеры

```bash
python3 .agents/skills/todone/scripts/tdone.py --root . --json
python3 .agents/skills/todone/scripts/tdone.py --root . --queue main --limit 10
```

## Ограничения

Состав команд задают точки входа. Модуль не выполняет команды и не меняет файлы
очередей.

## Связи

Скил `todone`; модули `queue.py`, `report.py`, `errors.py`, `schema.py`.
