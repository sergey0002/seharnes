# Полная карта live-файлов поставки `todone`

Эта карта перечисляет каждый live-файл под `todone/` (без `__pycache__`).
Для каждой строки указаны **зачем файл существует**, **почему и как он устроен**, **как его использовать**, с чем он связан и какой результат даёт.
Содержимое файла здесь не дублируется: источником поведения остаётся код, а карта
помогает выбрать правильный дом и не положить факт в чужой файл. Для каждой строки
отдельно указаны назначение, архитектурная причина, способ использования и связи.

## Принцип раскладки

| Слой | Дом | Правило |
|---|---|---|
| project | `<root>/.todone/` | registry, roles, tools проекта |
| queue | `<queue>/.todone/` | index, settings, data очереди |
| record | `data/T-NNN-тип/` | один `task.json` и файлы результата |
| skill | `assets/types/`, `assets/flows/`, `scripts/` | reusable code/config поставки |
| guidance | `docs/`, `references/child-skills/`, `references/` | progressive documentation |

## Как обновлять карту

1. Добавь/измени файл в правильном доме.
2. Обнови описание этого файла здесь, если путь новый или ответственность изменилась.
3. Пересобери `/home/user/preza/site/index.html` командой `python3 preza/build.py`: HTML использует тот же live-список.
4. Выполни `tcheck selftest`, `tcheck doctor --root todone/examples/v6-project --all --strict`, тесты и py_compile.
