# Каталог контрактов данных

Этот каталог содержит **человеческие названия и краткие назначения** машинных
контрактов. Идентификаторы в коде и JSON остаются каноническими; этот Markdown
только объясняет их смысл для человека и используется offline-каталогом при
построении карточек и навигации.

Если описание расходится с фактической схемой ключей, править нужно сначала
контракт и его проверку, затем эту справочную строку. Генератор не придумывает
описания по имени: для незаполненной строки он показывает технический ключ и
явно сообщает, что человеческое описание отсутствует.

## Откуда берётся описание

Порядок источников в карточке такой:

1. эта каноническая Markdown-таблица;
2. `title` из JSON Schema или имя контракта;
3. технический идентификатор с пометкой **«Описание не добавлено в каталог»**.

`keys`, `required` и типы полей по-прежнему берутся из фактической схемы или
реестра `scripts/tdcore/check_cli.py`; эта таблица не подменяет валидацию.
