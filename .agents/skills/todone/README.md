# todone

Управляет локальными очередями, JSON-записями, типами, потоками, доказательствами и отчётами через три точки входа: `tqueue` (очереди), `ttask` (записи) и `tcheck` (контроль/документация).

Навык предоставляет самодостаточную систему управления задачами с типизированными записями, потоками работы, JSON-схемами, шаблонами и встроенной автодокументацией. В поставке: 14 типов записей, 6 потоков, версионированные схемы, CLI с тремя точками входа, приёмочные тесты и пример проекта. Данные поставки лежат в `assets/` (типы, потоки, схемы, шаблоны, примеры, фикстуры); процедуры — в `references/child-skills/`; документация — в `docs/`.

## Основные возможности

- **Очереди** (`tqueue`): создание, регистрация, порядок, list/board.
- **Записи** (`ttask`): создание, чтение, правка, комментарии, рефы/артефакты, упаковка для субагентов.
- **Потоки** (`ttask flow`): запуск, state/next, контроль выборов, fan-out.
- **Типы и схемы** (`tcheck`): 14 встроенных типов, валидация, генерация документации.
- **Автодокументация** (`tcheck autodoc`): детерминированные бандлы JSON/HTML/Markdown с диаграммами.

## Быстрый старт

```bash
# В корне проекта
python3 -m todone.scripts.tqueue find
python3 -m todone.scripts.ttask new "Новая задача" --type task
python3 -m todone.scripts.tcheck doctor --all
```
