# Инструкция типа fix

## Когда применять
Применяй для дефекта с воспроизводимым наблюдаемым поведением.

## Цель
Устранить причину дефекта, не скрывая симптом и не расширяя границы.

## Как работать
Зафиксируй воспроизведение, найди причину, внеси минимальную правку, выполни тесты и проверь критерии. Оставь указатели на изменённые места.

## Запасной путь
Если git или code-graph недоступны, используй diff и чтение файлов; отсутствие инструмента укажи в отчёте.

## Результат
Верни воспроизведение, изменённые файлы, команды и свидетельства прогона.
