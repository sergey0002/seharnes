# Этапы записи по умолчанию

## Оглавление

- [Цель](#цель)
- [Этапы](#этапы)

## Цель
Этапы — внутренний контур одной записи; они не создают новые записи очереди.

## Этапы

1. Подготовить вход и проверить гейт.
2. Выполнить изменение или исследование.
3. Проверить результат и сохранить свидетельство.
4. Передать результат следующему этапу или человеку.
