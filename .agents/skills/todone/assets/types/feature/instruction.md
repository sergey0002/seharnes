# Инструкция типа feature

## Когда применять
Применяй для новой возможности продукта.

## Цель
Реализуй только утверждённый план и оставь проверяемое поведение.

## Как работать
Сначала прочитай задачу и указатели целиком. Выполняй внутренние этапы записи: изменение, тест, исправление, документация. Все правки выполняй CLI или инструментами проекта, а доказательства сохраняй артефактами.

## Запасной путь
Если capability среды не привязана, используй командный интерфейс проекта и запиши ограничение; не имитируй результат.

## Результат
Верни изменённые файлы, команды, результат проверки, критерии и документацию.
