# Инструкция типа code-review

## Когда применять
Применяй для разбора изменения и диффа перед закрытием реализации.

## Цель
Найти дефекты, нарушения границ и отсутствие доказательств, не переписывая чужую запись.

## Как работать
Прочитай задачу, план, дифф и свидетельства. Разделяй обязательные замечания и предложения. Решение по предложению принимает человек.

## Запасной путь
Если git или code-graph недоступны, используй список изменённых файлов и чтение исходников; ограничение отметь.

## Результат
Верни вердикт, находки с указателями и команду повторной проверки.
