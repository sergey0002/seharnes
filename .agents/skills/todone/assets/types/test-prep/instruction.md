# Инструкция типа test-prep

## Когда применять
Применяй для подготовки текстов тестов до реализации.

## Цель
Сделать ожидаемое поведение исполнимым и однозначным до изменения кода.

## Как работать
Свяжи тесты с критериями приёмки, не подменяй реализацию догадкой и передай результат `handoff`.

## Запасной путь
Если test-runner недоступен, подготовь исполнимые файлы тестов и опиши команду будущего прогона.

## Результат
Оставь тексты тестов, указатели и ожидаемый вердикт.
