# Инструкция типа mirror

## Когда применять
Применяй только для входа из внешней системы или дословного сырого текста.

## Цель
Сохранить происхождение: текст источника хранится в `source.raw` внутри `task.json` дословно.

## Как работать
Зеркало пишет только импорт. Не редактируй его, не комментируй внешнюю систему и не меняй его тип. Новый смысл оформляется дочерней записью типа `intake`.

## Запасной путь
Если соединение с источником недоступно, создай запись из полученного текста через `ttask new --from-file` и зафиксируй происхождение.

## Результат
Проверь наличие `source.raw`, идентификатора источника и номера ревизии.
