# Инструкция типа testing

## Когда применять
Применяй для общего прогона тестов и вердикта по критериям.

## Цель
Отделить факт прогона от предположения и вынести verdict_required по каждому критерию.

## Как работать
Запусти заявленные команды, сохрани полный результат артефактом, укажи окружение и свяжи verdict с `AC-N`.

## Запасной путь
Если test-runner недоступен, выполни команды вручную в окружении проекта и сохрани stdout, stderr и код возврата.

## Результат
Верни verdict, свидетельства и список непроверенных условий.
