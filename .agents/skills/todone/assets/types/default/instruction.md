# Инструкция типа default

## Когда применять
Применяй для работы, которая не требует специальной формы типа.

## Цель
Преобразуй задачу в проверяемый результат. Прочитай запись полностью, используй её указатели и не придумывай отсутствующие факты.

## Как работать
1. Уточни цель и границы по записи.
2. Сформулируй изменение, результат и способ проверки.
3. Правь только через CLI и оставь свидетельство результата.

## Гейты
Закрытие требует критериев приёмки и объявленного способа проверки.

## Запасной путь
Если инструмент среды недоступен, используй чтение файлов и команды проекта, а ограничение опиши в записи.

## Результат
Верни факты, указатели на файлы и команду проверки.
