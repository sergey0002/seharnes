# Отправить субагенту

```bash
ttask pack T-001 --queue site
ttask pack T-001 --mode handoff --last 3 --agent developer --queue site
```

Пакет собирается целиком из общего брифа, инструкции типа, тела записи,
выбранной ленты, refs, artifacts и `return_contract` агента. Ничего из истории
диалога родителя не наследуется.

Режимы пакета: `handoff`, `digest`, `comments`, `full`. `handoff` — последние K
реплик и все `handoff`; тексты не обрезаются. Обязательный контракт AGENT-1
содержит поля, форму, путь сохранения большого результата и pointer.

Нет `instruction.md`, общего брифа или обязательного поля — `PACK_INCOMPLETE`.
Границы: не менять type/id, не редактировать чужие записи/зеркало, не копировать
факт, не изображать capability и вернуть большой результат указателем.
