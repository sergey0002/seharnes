# Карта файлов

Подробная карта всех файлов поставки находится в `docs/13-file-map.md`.
Здесь достаточно правила навигации:

- `scripts/` — исполняемый код;
- `assets/types/` — JSON-плагины и инструкции;
- `assets/flows/` — маршруты;
- `assets/templates/` — стартовые формы;
- `assets/schemas/` — версионированные схемы;
- `assets/examples/` — примеры проектов;
- `assets/fixtures/` — валидные/негативные фикстуры;
- `references/` — короткие нормативные справочники;
  - `child-skills/` — процедуры по рабочим намерениям;
- `docs/` — объяснение архитектуры;
- `tests/` — проверка.

Перед изменением файла прочитай его назначение в полной карте и соответствующий
тест/CLI-контракт. После изменения запусти `tcheck selftest`, doctor и тесты.
