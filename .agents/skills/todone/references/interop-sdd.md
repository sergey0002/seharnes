# Внешний вход и SDD-системы

Внешний файл OpenSpec/Spec Kit/Jira импортируется в запись `mirror` тем же
локальным контрактом, что и любой другой вход. `source.raw` сохраняется
дословно, а метаданные используются для title/id/URL/комментариев и повторной
идемпотентности.

```bash
tcheck import openspec --file change.json --id change-1 --by importer
tcheck import speckit --file spec.json --by importer
```

После импорта работа продолжается в дочерней `intake`; зеркало read-only для
ручных `set`, `comment`, `ref`, `artifact` и других операций. Импорт печатает
команды, но не публикует детей автоматически.

Сетевые адаптеры, экспорт, перенос старой раскладки и обратная совместимость
не входят в v0.7; этот справочник описывает только локальный file-контур.
