# code

Назначение.
Расследование поведения кода CopyTrust: поиск истинной причины бага по
описанию, дифам, связанным задачам, документации, бизнес-логике и графу
вызовов. Скил выбирает дочерний скил и требует доказательств по каждому шагу.

Как работает.
Родитель принимает симптом, ожидание и номер задачи, затем передаёт работу
дочернему скилу bug-cause. Тот строит контракт поведения, путь по
бизнес-логике и путь по коду, проверяет гипотезы и возвращает отчёт с
доказательствами и отклонёнными версиями.

Что нужно.
Описание бага, ожидаемое поведение, доступ к коду, документации, графу кода и
логам стенда.

Чего не делает.
Не исправляет код без отдельной просьбы, не работает на проде и не выдаёт
гипотезу за причину без проверки.
