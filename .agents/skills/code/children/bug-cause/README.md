# bug-cause

Назначение.
Ищет истинную причину бага в коде: от контракта поведения и дифов до пути по
бизнес-логике, пути по коду и графа вызовов.

Как работает.
Собирает пакет задачи, связанные задачи и действующие бизнес-правила, поднимает
документацию домена, строит цепочку от действия пользователя до места ошибки. Затем формирует проверяемые
гипотезы, проверяет их по коду, данным и логами и оставляет одну причину с
доказательствами.

Что нужно.
Симптом, ожидаемое поведение, доступ к коду, документации, графу кода и логам
стенда. При наличии задачи нужны её `task.md`, `plan.md` и диф.

Чего не делает.
Не исправляет код без отдельной просьбы, не строит вывод на одном источнике и
не считает первую правдоподобную версию причиной.
