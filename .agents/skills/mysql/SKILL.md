# mysql

## Шаги

1. Проверь, что подключение относится к стенду текущего проекта. Используй
   существующие настройки, не печатай значения секретов.
2. Если соединение еще не установлено, используй `connect_db` с разрешенными
   настройками клиента. Для состава базы вызови `list_tables`.
3. Перед запросом данных вызови `describe_table` для нужных таблиц.
4. Выполни ограниченный SELECT через `query`, используя только подтвержденные
   колонки. Не выбирай персональные данные, которые не нужны задаче.
5. Отдели подтвержденные результаты от предположений. При недоступной базе
   укажи, что фактические данные не проверены.

## Границы

- `execute` разрешен только после отдельного явного разрешения пользователя.
- DDL, миграции и удаление данных не выполняются через этот скил.
- Не поднимай стенд и не меняй учетные данные ради чтения без разрешения.
- Занятый relay и ответ smoke `SKIP` сами по себе не означают отказ базы.
