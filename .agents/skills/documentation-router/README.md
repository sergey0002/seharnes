# documentation-router

Назначение.
Управляет документацией проекта: карта проекта, сверка документации с кодом и документация задачи. Применять по запросам документация, задокументируй проект, сверь документацию, task-doc.

Как работает.
Родитель принимает запрос, выбирает дочерний скил по маршрутизации и загружает его.

Что нужно.
Корень проекта и описание дочерних скилов.

Чего не делает.
Не дублирует код детей и не хранит их данные.
