## Суть
Скрипт является единой точкой доступа к структурированным данным задач и архитектуры в формате JSONdoc (`task.json`, `arch.json`). Он обеспечивает чтение указателей, выполнение поисковых запросов, транзакционную фиксацию изменений, генерацию производных представлений `doc.md` и валидацию схем.

## Когда запускать
Скрипт вызывается при получении контекста задачи (`jsondoc get`), фиксации проверенных фактов бизнес-логики (`jsondoc commit`), рендеринге `doc.md` и автоматической синхронизации метаданных задачи с архитектурной документацией.

## Коды выхода
| Код | Значение | Действие вызывающего |
|---|---|---|
| 0 | операция успешно выполнена, валидный JSON в stdout | обработать результат |
| 1 | целевой документ или запись не найдена | проверить существование задачи или указателя |
| 2 | ошибка валидации аргументов или синтаксиса | исправить параметры команды |
| 3 | конфликт параллельного изменения (concurrency conflict) | повторить операцию после перечитывания актуального состояния |
| 4 | требуется восстановление целостности транзакции | запустить recovery |

## Что читает и что пишет
Читает `task.json`, `arch.json`, схему и транзакционные чеки в `_jsondoc/`. Пишет обновленные JSON-документы и генерирует `doc.md` в `.doc/tasks/{task}/`. В stdout возвращает строго один валидный JSON-конверт.

## Побочные эффекты
Обновляет файлы знаний `task.json` и представления `doc.md`. Ведет учет транзакций в служебном каталоге `_jsondoc/`.

## Окружение и зависимости
Требуется Python 3.8+ со стандартными библиотеками и внутренними модулями пакета `jsondoc`.

## Ограничения
Изменение документов допускается только через специализированные команды `commit` и `apply`. Прямое редактирование `task.json` вручную запрещено архитектурным стандартом. Recovery JSONdoc проверяет owner-token `.lock`: локальный PID, которого больше нет, можно удалить под guard-lock; живой PID, другой host и повреждённый token остаются `lock_busy`. После reap следующая запись получает новый token.

## Связи
Основной инструмент управления знаниями задач в `task-doc`. Плановые подкоманды `plan write/verify/template` удалены вместе с JSON-моделью плана.
