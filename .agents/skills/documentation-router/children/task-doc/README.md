# task-doc

Назначение.
Зафиксировать прогресс, решения и подводные камни задачи, чтобы работа
продолжалась без потери контекста.

Как работает.
Два режима: погружение по описанию задачи в новом диалоге и документирование по
команде. В режиме документирования обновляет разделы задачи, сверяет связанную
архитектуру и пересобирает индекс задач. При наличии модели задачи читает и
пишет через JSONdoc.

Что нужно.
Описание задачи, текущий диф, решения по ходу работы и связанные архитектурные
документы.

Чего не делает.
Не переписывает описание задачи с нуля, не удаляет разделы без команды и не
правит сгенерированное представление руками.
