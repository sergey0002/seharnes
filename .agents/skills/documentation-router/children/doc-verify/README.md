# doc-verify

Назначение.
Держать архитектурные документы в соответствии с кодом, а не с памятью автора.

Как работает.
Берет из очереди один документ, читает его целиком, сверяет утверждения с кодом,
связями между документами и связанными задачами. Вносит точечные правки, отмечает
шаг выполненным и фиксирует найденные расхождения. Один запуск проверяет один
документ.

Что нужно.
Очередь сверки, доступ к коду и графам, индекс задач и связанные архитектурные
документы.

Чего не делает.
Не переписывает документ целиком, не создает новые документы задач и не
сканирует всю документацию подряд.
