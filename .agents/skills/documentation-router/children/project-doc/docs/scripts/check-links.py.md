## Суть
Проверка локальных ссылок в Markdown-файлах под `.doc/`. Игнорирует кодовые блоки (```), инлайн-код (` `), внешние URL (http/https/mailto/#/data/ftp/file), якоря. Рекурсивно обходит все `.md` файлы, пропуская `.doc/**/_jsondoc` и `vendor`. `--root` принимает корень проекта или сам каталог `.doc`, `--only` ограничивает обход одним подкаталогом. Выводит топ-5 директорий по числу битых ссылок и до 20 примеров. Возвращает код 1 если есть битые ссылки и код 2 если каталог для обхода не существует.

## Когда запускать
- В CI/пре-коммите для документации.
- После массовых правок в `.doc/architecture/` или `.doc/tasks/`.
- При команде «проверь ссылки в доках».
- Агент запускает после генерации/правки архитектурных документов.
- `validate_docs.py` вызывает проверку для `.doc/harnes` как гейт D07.

## Аргументы
| Аргумент | Алиас | Тип | Обязателен | По умолчанию | Что делает |
|---|---|---|---|---|---|
| --root |  | string | нет | . | Корень проекта или каталог `.doc`; скрипт сам определяет, где искать `.doc` |
| --only |  | string | нет |  | Обходить только этот подкаталог `.doc`, например `harnes` |
| --skip |  | string | нет |  | Пропустить каталог с таким именем внутри области обхода; можно повторять |
| --skip-historical |  | flag | нет |  | Пропустить документы со статусом `deprecated` и `frozen` |
| --quiet |  | flag | нет |  | Не выводить "links: OK" при успехе |

## Коды выхода
| Код | Значение | Действие вызывающего |
|---|---|---|
| 0 | Все локальные ссылки валидны | Успех |
| 1 | Найдены битые ссылки | Исправить цели ссылок или удалить ссылки |
| 2 | Каталог `.doc` или каталог `--only` не найден | Исправить `--root` или `--only`, не считать проверку пройденной |

## Что читает и что пишет
**Читает:**
- `.doc/**/*.md` — все Markdown-файлы документации (кроме `_jsondoc/`, `vendor/`)
- при `--only` только файлы указанного подкаталога `.doc`
- при `--skip` каталоги с указанными именами не обходятся

**Пишет:**
- Ничего (только stdout: список битых ссылок или "links: OK")

## Ограничения
- Не проверяет внешние URL (http/https) — только локальные относительные пути к `.md`.
- Игнорирует якоря (`#section`) — проверяет только файл.
- Не разрешает symlinks — проверяет физическое существование файла.
- Пропускает `_jsondoc/` и `vendor/` полностью.
- Не проверяет ссылки в сгенерированных файлах (если они не в исключённых папках).

## Связи

- Результат используется: фиксация битых ссылок перед коммитом/пушем
