## Суть
Находит устаревшие архитектурные документы: код изменился после последнего обновления документа (поле `updated:` в meta-блоке). Для каждого `.md` в `.doc/architecture/`: извлекает дату `updated:`, находит все упомянутые файлы проекта (в backtick-кавычках), проверяет `git log` — были ли эти файлы изменены после `updated`. Выводит отчёт: какие документы нужно обновить, какие файлы изменились, сколько коммитов и последний коммит. Поддерживает фильтр по дополнительному порогу дней (`-Days`) и проверку конкретного документа (`-Section`).

## Когда запускать
- Периодически (еженедельно) для контроля актуальности документации.
- После крупных изменений в кодовой базе.
- По команде «обнови устаревшие документы» — агент читает отчёт и обновляет затронутые секции.
- При подготовке релиза для выявления рассинхронизации docs ↔ код.

## Аргументы
| Аргумент | Алиас | Тип | Обязателен | По умолчанию | Что делает |
|---|---|---|---|---|---|
| -Days |  | int | нет | 0 | Дополнительный порог: показывать только если файл изменялся в последние N дней (0 = все) |
| -Section |  | string | нет | "" | Проверить только конкретный документ (имя файла без пути, напр. `payments.md`) |

## Коды выхода
| Код | Значение | Действие вызывающего |
|---|---|---|
| 0 | Нет устаревших документов (или git недоступен) | Всё актуально |
| 1 | Есть устаревшие документы | Требуется обновление |

## Что читает и что пишет
**Читает:**
- `.doc/architecture/*.md` — архитектурные документы (кроме `_map/`, `_*`)
- Meta-блок каждого документа: поле `updated:`
- Backtick-ссылки на код: `` `path/to/file.php` `` (с опциональным `:line`)
- `git log --since=... --oneline -- <file>` — история изменений файлов

**Пишет:**
- Ничего (только stdout: структурированный отчёт).

## Побочные эффекты
- Нет побочных эффектов (read-only).

## Окружение и зависимости
- Требует `git` (для проверки истории изменений).
- Использует `_lib.ps1`: `Get-ArchitectureDocs`, `Get-DocCodeRefs`, `Get-DocMeta`, `Read-TextFile`, `Test-GitAvailable`, `Normalize-RelativePath`.

## Примеры
```powershell

# Только файлы, изменившиеся за последние 30 дней
powershell .agents/skills/documentation-router/children/project-doc/scripts/sync-docs.ps1 -Days 30
```

## Ограничения
- Работает только с backtick-ссылками в архитектуре; не видит упоминания в простом тексте.
- Требует корректное поле `updated:` в формате `YYYY-MM-DD` в meta-блоке.
- `git log` проверяет каждый файл отдельно — может быть медленно на большом числе ссылок.
- Не учитывает изменения в файлах, НЕ упомянутых в документе (только перечисленные backtick-пути).
- Если git недоступен — показывает только структуру (нет проверки изменений).

## Связи
- Вызывается: агент по команде «обнови устаревшие документы», вручную, CI
- Зависит от: `git`, архитектурных документов с meta.updated и backtick-ссылками
- Результат используется: агент обновляет только затронутые секции документов, `get-verify-batch.ps1 -ResetStale` использует аналогичную логику
