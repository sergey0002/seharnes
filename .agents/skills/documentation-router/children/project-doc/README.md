# project-doc

Назначение.
Вести документацию проекта по разделам и не плодить лишние документы.

Как работает.
Работает режимами: инициализация, карта проекта, разбор раздела, аудит,
валидация и синхронизация. Перед созданием документа проверяет, не подходит ли
уже существующий. При разборе раздела опирается на граф кода, идет батчами и
показывает покрытие.

Что нужно.
Индекс архитектуры, карта документов, граф кода и скрипты сбора батчей.

Чего не делает.
Не перезаписывает документы целиком, не сканирует всю документацию подряд и не
создает новые разделы без проверки существующих.
