# Graphiti MCP

Retrieves durable project decisions, their sources and dates of validity.
Authorized records store one self-contained event per episode.

Search runs before recording to avoid duplicate facts.
Episode inspection distinguishes accepted work from completed extraction.
The configured project group isolates reads and writes from other repositories.

Secrets and customer personal data are excluded.
Deletion and graph clearing require explicit authorization.
The bundled server document preserves configuration details and operational history.
