# Самопроверка автора плана

Внутренний контроль перед передачей плана в `audit-plan`. Это не независимый
аудит. Его цель - не отдавать аудитору заведомо пустые поля.

## Структура

- [ ] `scope_size` записан и соответствует числу независимых причин;
- [ ] Diff principle N равно числу файлов в разделе `## Правки по файлам`;
- [ ] у каждого файла указаны `**R:**` и `**Verified by:**`;
- [ ] пустые необязательные секции помечены одной строкой `N/A`, а не выдуманы.

## Патчи

- [ ] каждый Before скопирован из чтения текущей сессии;
- [ ] каждый Before находится поиском ровно один раз в файле;
- [ ] каждый After полон, без многоточий и описаний вместо кода;
- [ ] измененные локальные переменные проверены по всем поздним чтениям в файле;
- [ ] все вызывающие из радиуса прочитаны целиком.

## Требования и сценарии

- [ ] все T-id из AC, R и S есть в таблице источников;
- [ ] AC-ID совпадают в Acceptance criteria и Coverage matrix;
- [ ] у каждой причины R есть сценарий S;
- [ ] ожидаемый результат литеральный: строка, число, код, значение в БД;
- [ ] `php -l`, `no errors` и `should work` не стоят как результат поведения;
- [ ] каждый связанный номер задачи имеет ссылку на `task.md` или
  `none: not exported`.

## Достоверность

- [ ] as-is взят из кода, а не из документации;
- [ ] расхождение документации и кода записано одной строкой;
- [ ] инварианты из истории строк и связанных задач сохранены в After;
- [ ] для общего кода есть таблица IN/OUT и шаг регрессии на OUT-вызывающего;
- [ ] риск по P1.2 записан рядом с каждым файлом.

## Запреты

- [ ] в плане нет ссылок на удаленные артефакты: JSON-модель, механический
  валидатор, research-ledger, plan-audit.md, plan_hash;
- [ ] нет открытого выбора, который аудитор должен сделать за автора;
- [ ] `status: ready` не выставлен до прохода аудита с вердиктом `pass`;
- [ ] `plan_rev` поднят, если план менялся после последнего прохода.
