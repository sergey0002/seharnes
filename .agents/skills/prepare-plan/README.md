# prepare-plan

Назначение.
Пишет исполнимый план правок по задаче: причина, точные фрагменты до и после,
источники истины, критерии приёмки и проверяемые сценарии. План рассчитан на
исполнение дешевой моделью без догадок.

Как работает.
Читает бриф и доменную документацию, пересобирает радиус изменений по графу кода
и истории строк, собирает инварианты и связанные задачи. Затем пишет авторский
plan.md по шаблону, обновляет матрицу тестов и проходит самопроверку. Готовность
подтверждает отдельный скил audit-plan: он правит этот же план на месте и ведет журнал проходов.

Что нужно.
Номер задачи и task.md, доступ к документации проекта, графу кода, истории git и
схеме БД. Адреса инструментов и команд лежат в ADAPTERS.local.md.

Чего не делает.
Не меняет продуктовый код. Не выполняет независимый аудит и не ставит статус
ready без прохода аудита с вердиктом pass. Не запускает тесты, не документирует задачу и не делает code
review.
