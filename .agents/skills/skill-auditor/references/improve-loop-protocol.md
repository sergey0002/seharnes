# Протокол безопасного цикла авто-улучшения (`Bounded Improve Loop` v3.0)

Загружайте этот документ **только** когда пользователь явно просит доработать или итеративно исправить целевой скил в цикле до целевого качества. По умолчанию `skill-auditor` работает строго в режиме чтения (`read-only`).

---

## 1. Обязательные защитные инварианты цикла

1. **Явное разрешение человека (HITL Gate):** Запрещено редактировать файлы внутри `<target_path>` без явного подтверждения пользователя (название режима «исправь/улучши скил» или одобрение плана правок).
2. **Mechanical Scope Guard (Жёсткий контур изменений):** Зафиксируйте список файлов внутри `<target_path>` до старта. Любая правка разрешена **только** внутри `<target_path>` — запрещено трогать системные конфиги (`CLAUDE.md`, `MEMORY.md`, `~/.claude/`, соседние проекты).
3. **Anti-Guarantee-Weakening Rule (Защита от «хака метрик»):** Запрещено закрывать замечания путём **удаления или ослабления реальных инвариантов** (снимать проверки безопасности, удалять валидации, ослаблять ассерты в `evals/` или удалять нужные `D6`/`D7` гейты ради красивого балла).
4. **Ограниченный бюджет раундов (`max_rounds = 3`, потолок `5`):** При отсутствии прогресса цикл останавливается с эскалацией пользователю.

---

## 2. Пошаговый алгоритм раунда (`Round R = 1..max_rounds`)

1. **Baseline (`Round 0`):** Проведите аудит целевого скила через `static_audit.py` + проходы + `score_aggregator.py`, сохраните `<audit_workspace>/summary_r0.json` (журнал находок).
2. **Точечный патч (Fix Pass):** Исправляйте **P0 → P1 → Top-ROI P2** за один согласованный проход (не трогая посторонний код и не добавляя `FLUFF`/`CAGE`/`SCAR`). Если правятся скрипты — проверьте синтаксис и тесты сразу после правки.
3. **Повторный аудит и Cross-Round Ledger:** Запустите аудит заново и сравните с предыдущим раундом через встроенный ledger в `score_aggregator.py`:
   ```bash
   python3 <skill_auditor_dir>/scripts/score_aggregator.py \
     --static <audit_workspace>/static_rN.json \
     --findings <audit_workspace>/rN/finding_*.json \
     --compare-prev <audit_workspace>/summary_rPrev.json \
     --output <audit_workspace>/summary_rN.json \
     --markdown-out <audit_workspace>/summary_rN.md
   ```
4. **Условия остановки (`Termination Criteria`):**
   - **Сходимость (`converged: true`):** 0 открытых `P0`/`P1`, `security_gate == "CLEAR"`, `guarantee_weakening_alerts == []` — цикл успешно завершён!
   - **Не-сходимость (`non_convergence_warning: true`):** 2 раунда подряд `score_delta <= 0` при открытых `P0/P1` или возникают «качели» правок — **немедленный стоп и эскалация пользователю** с выпиской конфликтующих ограничений.
   - **Тревога ослабления (`guarantee_weakening_alerts` непуст):** немедленный откат последнего изменения, вызвавшего просадку `D6`/`D7` или покрытия, и пересмотр фикса.
