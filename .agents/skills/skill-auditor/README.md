# skill-auditor

Аудит и постепенное улучшение скиллов, архивов `.skill`, субагентов, дочерних
скиллов, конфигураций MCP, `AGENTS.md`, правил `.mdc` и целых каталогов скиллов.
Проверяет переносимость между агентами, безопасность, срабатывание триггеров,
контекстный бюджет и полноту покрытия. Ранжирует находки по P0/P1/P2 и
предлагает правки в формате Before/After.

## Когда применять

- Аудит скилла, проверка `SKILL.md` или `AGENTS.md`.
- Оценка переносимости между Claude Code, Codex, Cursor, Kilo, Qoder и другими агентами.
- Сравнение A/B и runtime-оценка работы скилла.
- Рефакторинг или упаковка скилла в архив.

Не применяется для обычного code review и создания скилла с нуля.

## Состав пакета

- `SKILL.md` - рубрикатор D1-D8, гейты и режимы прогона.
- `references/agents/` - 7 профилей аудиторов и синтезатор.
- `scripts/` - статический аудит, раннер оценок, агрегатор баллов, самотест.
- `tests/evals/` - наборы оценок и триггерных запросов.
- `assets/audit-report-template.md` - шаблон отчёта.
- `references/` - рубрики, методология расширения, каталоги запахов.
- `references/README-upstream.md` - полное описание upstream-пакета.

## Запуск

`python3 scripts/static_audit.py --target <path>` собирает статические
находки. Полный прогон и критерии описаны в `SKILL.md`. Правки целевого
пакета выполняются только после явного разрешения пользователя.
