## Суть
Скрипт выполняет статический анализ правил агента и файлов навыков `SKILL.md`. Он проверяет целостность перекрестных ссылок на существующие навыки, корректность путей к вызываемым скриптам, отсутствие дублирования триггеров и циклических зависимостей, а также отслеживает дельту проблем относительно предыдущего прогона.

## Когда запускать
Скрипт вызывается при изменении правил в `.cursor/rules/`, изменении файлов навыков `.agents/skills/` и автоматически при проверке гейта `rules` в `harness_cli.py doctor`. Запуск безопасен в любое время.

## Аргументы
| Аргумент | Алиас | Тип | Обязателен | По умолчанию | Что делает |
|---|---|---|---|---|---|
| `--rules-dir` | нет | Path | да | нет | путь к каталогу правил (.cursor/rules) |
| `--skills-dir` | нет | Path | да | нет | путь к каталогу навыков (.agents/skills) |

## Коды выхода
| Код | Значение | Действие вызывающего |
|---|---|---|
| 0 | ошибок не обнаружено, статус passed | продолжить выполнение пайплайна |
| 1 | обнаружены критические ошибки, статус failed | исправить несуществующие ссылки на скрипты или навыки |

## Что читает и что пишет
Читает все файлы `.md` и `.mdc` в каталоге правил и все файлы `SKILL.md` в каталоге навыков. Для фиксации базового состояния пишет файл снимка в `.doc/harnes/state/.validate-rules-last.json`. В stdout выводит отчет в формате JSON.

## Побочные эффекты
Обновляет файл состояния `.doc/harnes/state/.validate-rules-last.json` для вычисления дельты новых и устраненных замечаний. Не выполняет сетевых запросов и не меняет конфигурации.

## Окружение и зависимости
Требуется Python 3.8+ со стандартными библиотеками `argparse`, `hashlib`, `json`, `re`, `pathlib`, `functools`.

## Примеры
```bash
python3 .agents/skills/harness-router/children/improvement/scripts/validate_rules.py \
  --rules-dir .cursor/rules \
  --skills-dir .agents/skills
```

## Ограничения
Статический анализатор проверяет синтаксические ссылки на имена файлов и навыки. Он не проверяет runtime-поведение или контекстную применимость инструкций агента.

## Связи
Вызывается скриптом `harness_cli.py doctor` в составе гейта `rules`. Входит в контур контроля целостности харнеса навыка `improvement`.
