## Суть
Скрипт проверяет наличие и структуру документации компонентов харнеса. Он контролирует наличие `README.md` у каждого скила, актуальность размещения документов серверов MCP из `.cursor/mcp.json`, обязательные заголовки существующих документов скриптов и локальные ссылки в активных документах `.doc/harnes` (код D07). В проверку D07 входят `status: actual` и документы без статуса; каталоги `archive`, `idea`, `astra_plan`, `plan`, `audit`, `hermes`, `openhands`, а также документы со статусом `deprecated` и `frozen` исключены как исторические.

## Когда запускать
Скрипт запускается при аудите целостности документации харнеса, перед сдачей задач по изменению скилов или MCP-серверов, а также в составе комплексного чека `harness doctor`. Запуск не вовремя безопасен, так как скрипт работает в режиме только для чтения.

## Аргументы
| Аргумент | Алиас | Тип | Обязателен | По умолчанию | Что делает |
|---|---|---|---|---|---|
| `--root` | нет | string | нет | . | путь к корню репозитория для проверки |
| `--warn-only` | нет | flag | нет | выключен | завершать работу с кодом 0 даже при наличии ошибок |
| `--json` | нет | flag | нет | выключен | выводить результат проверки в формате JSON |

## Коды выхода
| Код | Значение | Действие вызывающего |
|---|---|---|
| 0 | ошибок документации не обнаружено или включен режим `--warn-only` | продолжить выполнение пайплайна |
| 1 | обнаружены отсутствующие файлы документации или ошибки структуры | исправить ошибки документации по списку |

## Что читает и что пишет
Читает дерево каталогов `.agents/skills/**`, конфигурацию `.cursor/mcp.json`, файлы документов `.agents/skills/**/docs/scripts/*.md` и активные Markdown-файлы `.doc/harnes/**`. Для D07 использует `check-links.py` из скила `project-doc`. Ничего не пишет на диск, выводит отчет в stdout.

## Побочные эффекты
Побочных эффектов нет. Сетевые запросы, изменение файлов, обращение к базам данных и запуск процессов не выполняются.

## Окружение и зависимости
Требуется Python 3.8+ со стандартной библиотекой (`argparse`, `json`, `re`, `pathlib`). Запускается из любой рабочей директории при указании `--root`.

## Примеры
```bash
python3 .agents/skills/harness-router/children/improvement/scripts/validate_docs.py
python3 .agents/skills/harness-router/children/improvement/scripts/validate_docs.py --json
python3 .agents/skills/harness-router/children/improvement/scripts/validate_docs.py --root . --warn-only
```

## Ограничения
Не проверяет фактическую смысловую полноту текстов документации. Анализирует синтаксическое наличие файлов и разделов второго уровня (`##`) и локальные ссылки в активных документах `.doc/harnes`. Ссылки в `.doc/architecture`, `.doc/tasks` и исторических разделах харнеса проверяются отдельно через `check-links.py` и `doc-verify`.

## Связи
Вызывается скриптами `harness_cli.py doctor`, используется скилом `improvement` для контроля целостности документации. Результаты соотносятся с требованиями стандарта [.doc/harnes/component-docs.md](../../../../../../.doc/harnes/component-docs.md).
