## Суть
Скрипт проверяет соответствие навыков агента стандарту [.doc/harnes/skill-format.md](../../../../../../.doc/harnes/skill-format.md). Он контролирует корректность YAML frontmatter в `SKILL.md`, наличие `README.md`, структуру манифеста `skill.json`, разрешенные подкаталоги, отсутствие циклических зависимостей между навыками и лимиты строк. Обход рекурсивный: проверяются все `SKILL.md` под `--skills-root`, включая `children/` любой глубины.

## Когда запускать
Скрипт запускается при создании нового навыка, изменении существующих `SKILL.md` и манифестов, а также автоматически в составе комплексной проверки `harness_cli.py doctor`.

## Аргументы
| Аргумент | Алиас | Тип | Обязателен | По умолчанию | Что делает |
|---|---|---|---|---|---|
| `--skills-root` | нет | string | нет | .agents/skills | корень дерева навыков; обход идет рекурсивно по всем вложенным `SKILL.md` |
| `--warn-only` | нет | flag | нет | выключен | завершать работу с кодом 0 даже при наличии ошибок |
| `--json` | нет | flag | нет | выключен | выводить результат проверки в формате JSON |
| `--policy-root` | нет | path | нет | не задан | проверять YAML-политики проекта и применять часть ограничений без ослабления встроенных правил |

## Коды выхода
| Код | Значение | Действие вызывающего |
|---|---|---|
| 0 | все навыки валидны или включен режим `--warn-only` | продолжить выполнение пайплайна |
| 1 | обнаружены критические ошибки структуры навыков | исправить ошибки структуры или манифеста |
| 2 | каталог навыков не найден | проверить путь к каталогу навыков |

## Что читает и что пишет
Читает каталог навыков `.agents/skills`, файлы `SKILL.md`, `README.md` и `skill.json`. Выводит текстовый или JSON отчет в stdout, на диск ничего не пишет.

## Побочные эффекты
Побочных эффектов нет. Сетевые запросы, изменение файлов и баз данных не выполняются.

## Окружение и зависимости
Требуется Python 3.8+ со стандартными библиотеками `argparse`, `json`, `os`, `re`, `sys`, `pathlib`.

## Примеры
```bash
python3 .agents/skills/harness-router/children/improvement/scripts/validate_skills.py
python3 .agents/skills/harness-router/children/improvement/scripts/validate_skills.py --json
python3 .agents/skills/harness-router/children/improvement/scripts/validate_skills.py --skills-root .agents/skills --warn-only
```

## Ограничения
Проверяет структуру и синтаксическую форму файлов навыка на всех уровнях вложенности. Не оценивает логическое качество и применимость инструкций в промптах. Папки внутри `references/`, `assets/` и `tests/` не считаются отдельными навыками: учитываются только каталоги с `SKILL.md`. `--policy-root` использует только часть правил YAML; ошибка политики всегда возвращает код 1, включая `--warn-only`.

## Связи
Вызывается в составе проверок целостности харнеса через `harness_cli.py doctor`. Контролирует соблюдение формата из [.doc/harnes/skill-format.md](../../../../../../.doc/harnes/skill-format.md).
