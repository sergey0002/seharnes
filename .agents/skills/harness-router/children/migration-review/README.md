# migration-review

Назначение.
Разбирает результат переноса харнеса и показывает, какие локальные скилы,
правила и MCP-серверы остались от исходного проекта.

Как работает.
Скил читает бэкап конфликтов, сканирует текущий канон, правила и MCP-конфиги,
строит предложения и применяет только безопасные из них. Конфликты с одинаковыми
именами остаются на ручной разбор.

Что нужно.
Корень нового проекта, Python 3, файлы `.doc/.rebase-conflicts.json` и
`.doc/.rebase-backup/`, созданные переносом.

Чего не делает.
Не выбирает версию конфликтующего скила, не сливает правила автоматически и не
копирует секреты из старого MCP-конфига. Бэкап удаляет только по отдельной
команде `--rm-backup --yes`.
