## Суть
Проверяет, что у каждого активного MCP-сервера есть скил и документ в
`{skill}/docs/mcp/{server}.md`. Переносит документы из `.doc/harnes/mcp/` в скил,
когда скил уже создан. Аудит выявляет дубли документов, неполные скилы и битые
локальные ссылки, включая `meta.related`.

## Когда запускать
После добавления, переименования или включения MCP-сервера, а также в гейте
`docs-mcp` команды `harness doctor`. Без запуска документ остается в `.doc`, а
сервер считается незакрытым.

## Аргументы
| Аргумент | Алиас | Тип | Обязателен | По умолчанию | Что делает |
|---|---|---|---|---|---|
| `--list` | нет | флаг | нет | выключен | показать серверы, скилы, документы и статус |
| `--move` | нет | флаг | нет | выключен | перенести документы в скилы, если скил уже есть |
| `--audit` | нет | флаг | нет | выключен | проверить скилы и документы всех серверов |
| `--policy-root` | нет | путь | нет | не задан | при аудите проверить дополнительное расположение MCP-документа из политики без снятия встроенных проверок |

## Коды выхода
| Код | Значение | Действие вызывающего |
|---|---|---|
| 0 | все активные серверы закрыты | продолжить |
| 1 | нет скила или его файлов, документ отсутствует, продублирован, не перенесен или содержит битую ссылку | исправить ошибку и повторить аудит |
| 2 | неверные аргументы или запрошена справка | передать корректные аргументы |

## Что читает и что пишет
Читает `.cursor/mcp.json`, дерево `.agents/skills/**/SKILL.md` и документы
`.doc/harnes/mcp/`. С `--move` переносит файл в `{skill}/docs/mcp/`. Без `--move`
ничего не пишет.

## Побочные эффекты
С `--move` перемещает файлы документов. Без `--move` побочных эффектов нет. Сеть,
база, git и контейнеры не затрагиваются.

## Окружение и зависимости
Переменных окружения не требуется. Нужен Python 3.8+ и стандартная библиотека.

## Примеры
```bash
python3 .agents/skills/harness-router/children/doc-mcp/scripts/doc_mcp.py --list
python3 .agents/skills/harness-router/children/doc-mcp/scripts/doc_mcp.py --move
python3 .agents/skills/harness-router/children/doc-mcp/scripts/doc_mcp.py --audit
```

## Ограничения
Сопоставление сервера и скила идет по имени, плюс алиас `jira-task -> jira`.
Остальные несовпадения считаются ошибкой. Отключенные
серверы не требуют скила, но обязаны иметь документ с причиной отключения.
Скрипт проверяет наличие документа отключенного сервера, причину отключения
проверяет агент. `--move` не пересчитывает относительные ссылки: после переноса
агент обновляет локальные и входящие ссылки и выполняет `--audit`.
