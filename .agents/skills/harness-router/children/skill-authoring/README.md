# skill-authoring

Назначение.
Создает новые скилы по формату харнеса и проверяет существующие скилы на
соответствие правилам структуры и документации.

Как работает.
Создание пишет SKILL.md, README.md и skill.json, затем передает скил в add-skill
для карточки, индексов, реестра и родительского роутера. Аудит проверяет
структуру, тексты, документацию, реестр и зависимости и возвращает отчет. Установка через add-skill проверяет индексы и копии; `runtime_registration.py` показывает состояние конфигов, но не подтверждает обнаружение в UI. Sync блокируется при нарушении visibility-контракта правил.

Что нужно.
Корень проекта, Python 3 и доступ к канону `.agents/skills`.

Чего не делает.
Не пишет смысловые шаги вместо автора скила, не исправляет найденные ошибки и не
заменяет runtime-проверку в редакторе.
