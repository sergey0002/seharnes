# copy-project

Назначение.
Переносит Git-состояние проекта в новую папку без harness и готовит отчёт о том,
что нужно доделать для запуска.

Как работает.
Скрипт копирует отслеживаемые файлы и каталог `.git` во временный каталог,
исключает harness и секретные env-файлы даже если Git отслеживает их, затем пишет
STARTUP-REQUIRED.md. В копии удаляются `.git/worktrees` и lock-файлы, чтобы
worktree-регистрации не указывали на исходный репозиторий. История `.git` и
remotes сохраняются как есть.

Что нужно.
Путь к Git-репозиторию и путь к новой папке. Значения секретов вводит оператор
или хранилище секретов, не скрипт.

Чего не делает.
Не переносит harness-kit, не дампит базу, не устанавливает зависимости, не
запускает приложение и не меняет источник. `.git` может содержать токены в
remotes, hooks и секреты в истории; такие данные не вычищаются. Перенос kit
выполняет `new-project`; межсредовые зеркала обновляет `environment-sync`.
