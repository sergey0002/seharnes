# harness-core

Назначение.
Управляет харнесом: синхронизацией сред, переносом kit, настройкой проекта, аудитом MCP и картой харнеса.

Как работает.
Загружает конфиги сред и kit, вызывает нужный дочерний сценарий, печатает отчет и проверяет результат.

Что нужно.
Python 3, PowerShell для экспорта, Node для MCP, доступ к проекту и конфигам.

Чего не делает.
Не дублирует код дочерних скилов, не коммитит изменения и не хранит состояние внутри скилов.
