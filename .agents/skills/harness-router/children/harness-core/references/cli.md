# CLI

Команды `harness_cli.py`:

- `doctor` - проверка конфигов и адаптеров.
- `sync --dry-run` - план синхронизации без записи.
- `sync --yes` - применение синхронизации.
- `export --target <path>` - перенос kit.
- `setup` - настройка проекта.
- `mcp-audit` - список MCP-серверов.
- `verify` - проверка паритета.

Exit codes: `0` успех, `1` отказ или ошибка проверки, `2` ошибка конфигурации.
