## Суть
Синхронизация представлений сред агентов (Codex, Kilo, Antigravity, Qoder, Qwen)
с каноническим источником `.cursor/` и `.agents/skills/`. Генерирует адаптированные
конфигурации MCP, правила и скилы без использования небезопасных симлинков, очищает
байткод-кеши и создает изолированные представления. После parity-report выполняет
trigger-проверку и visibility-гейт через harness mirror.

## Когда запускать
Запускать после любых правок правил канона `.cursor/rules/`, канонических скилов
`.agents/skills/` или конфигурации `.cursor/mcp.json`.
Не запускать без предварительной проверки валидаторами канона.

## Аргументы
| Аргумент | Алиас | Тип | Обязателен | По умолчанию | Что делает |
|---|---|---|---|---|---|
| `--install-windows-mcp` | нет | флаг | нет | не требуется | сохранён для существующих вызовов; Windows-конфиг заменяется без флага |
| `--local-only` | нет | флаг | нет | false | Не менять глобальные конфигурации сред |
| `--replace-managed-mcp` | нет | флаг | нет | false | Разрешить замену просмотренных управляемых MCP Qoder с резервной копией |

## Коды выхода
| Код | Значение | Действие вызывающего |
|---|---|---|
| 0 | генераторы, parity, rule-trigger и visibility-гейты прошли | проверить итоговый parity-report |
| >0 | ошибка генератора или прав доступа | устранить причину сбоя в генераторах |

## Что читает и что пишет
Читает `.cursor/mcp.json`, `.cursor/rules/`, `.agents/skills/`.
Генерирует файлы в `.codex/`, `.kilo/`, `.qoder/`, `.qwen/`,
`.doc/skil_data/harness-core/`. Удаляет устаревшие артефакты и директории `__pycache__`.
Codex и Cursor читают `.agents/skills` напрямую. Старые копии удаляются после сохранения отличающихся файлов в бэкап. Проверка `native-discovery` сверяет регистрацию вложенных скилов и bootstrap.

## Побочные эффекты
Перезаписывает сгенерированные файлы представлений сред и настройки MCP.
Удаляет лишние файлы из управляемых копий скриптов, правил и скилов; локальные
дополнения в этих каталогах не сохраняются.
При наличии каталога Windows Antigravity заменяет глобальный `mcp_config.json`
конфигурацией текущего проекта и проверяет её побайтово.

## Окружение и зависимости
Требует `bash`, `python3`, стандартные утилиты POSIX.
Запускается относительно корня репозитория.

## Примеры
```bash
bash .agents/skills/harness-router/children/environment-sync/scripts/sync-agent-views.sh
bash .agents/skills/harness-router/children/environment-sync/scripts/sync-agent-views.sh --install-windows-mcp
```

## Ограничения
В `.codex/config.toml` заменяет MCP-секции, сохраняя остальные настройки и существующую политику подтверждений Codex.
Для сред с разными разделителями путей генерирует платформо-зависимые адаптеры.

## Локальная синхронизация

`--local-only` или `HARNESS_SYNC_LOCAL_ONLY=1` запрещает менять глобальные конфиги Antigravity на Linux/Windows. Перенос проекта всегда использует этот режим. Проектные файлы и проверки остаются теми же.

Перед изменением представлений запускается Qoder `--preflight`. Неизвестные файлы, симлинки и MCP-серверы Qoder останавливают синхронизацию с кодом 3 до запуска остальных генераторов. Изменённые файлы управляемых путей Qoder сохраняются в `.doc/skil_data/environment-sync/backups/qoder-preflight/` перед заменой. При отличии существующего MCP-сервера его замена разрешается только после просмотра с флагом `--replace-managed-mcp`; неизвестные серверы этот флаг не удаляет.
