## Суть
Сверка сгенерированных представлений сред (Codex, Kilo, Agents, Qoder, Qwen)
с каноническим источником `.cursor/` и `.agents/skills/`. Сравнивает деревья каталогов
побайтово после нормализации переносов строк (CRLF -> LF), а правила проверяет по
телу документа без YAML frontmatter с нормализацией целей локальных ссылок.

## Когда запускать
Запускать после генерации представлений или в гейте `parity` команды `harness doctor`,
а также в pre-commit/CI для выявления расхождений между каноном и зеркалами.
Не запускать без предварительного запуска синхронизации при правках канона.

## Аргументы
| Аргумент | Алиас | Тип | Обязателен | По умолчанию | Что делает |
|---|---|---|---|---|---|
| `--canonical` | нет | путь | да | нет | путь к каноническому каталогу |
| `--view` | нет | путь | нет | нет | путь к каталогу зеркала, можно повторять |
| `--manifest` | нет | путь | нет | нет | путь к файлу отчета манифеста parity |
| `--check` | нет | флаг | нет | выключен | режим проверки свежести манифеста без перезаписи |
| `--rules-canonical` | нет | путь | нет | нет | путь к каноническому каталогу правил |
| `--rules-view` | нет | путь | нет | нет | путь к каталогу правил зеркала, можно повторять |
| `--allow-extra` | нет | флаг | нет | выключен | считать локальные дополнения зеркал допустимыми |
| `--mcp-canonical` | нет | путь | нет | нет | путь к каноническому mcp.json |
| `--mcp-view` | нет | путь | нет | нет | путь к зеркалу mcp.json, можно повторять |

## Коды выхода
| Код | Значение | Действие вызывающего |
|---|---|---|
| 0 | паритет подтвержден, расхождений нет | продолжить выполнение пайплайна |
| 1 | обнаружен дрифт между каноном и зеркалами или устаревший манифест | перезапустить `sync-agent-views.sh` |
| 2 | ошибка переданных параметров командной строки | исправить аргументы вызова |

## Что читает и что пишет
Читает канонические файлы и файлы зеркал, а также манифест parity.
В режиме по умолчанию пишет отчет в файл `--manifest`. В stdout выводит итоговый
JSON-отчет со статусом, списком ошибок и хешем канона.

## Побочные эффекты
Перезаписывает файл манифеста при обычном запуске. В режиме `--check` файловую
систему не модифицирует.

## Окружение и зависимости
Требует `python3` (версии 3.8+). Использует только стандартную библиотеку Python
(`hashlib`, `json`, `argparse`, `pathlib`).

## Примеры
```bash
python3 .agents/skills/harness-router/children/environment-sync/scripts/verify_parity.py \
  --canonical .agents/skills \
  --view .kilo/skills \
  --manifest .doc/skil_data/harness-core/parity-report.json

python3 .agents/skills/harness-router/children/environment-sync/scripts/verify_parity.py \
  --canonical .agents/skills \
  --manifest .doc/skil_data/harness-core/parity-report.json \
  --check
```

## Ограничения
Бинарные файлы сравниваются строго без нормализации.
Файлы `ADAPTERS.local.md` исключаются из проверки дрифта по соглашению.

## Связи
Скил: `harness-core`, `environment-sync`. Гейт: `parity` в `harness doctor`.
Вызывается после `sync-agent-views.sh`.
