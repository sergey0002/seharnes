## Суть

Читает переключатели сред, не загружая скрипты из целевого проекта.

## Когда запускать

Для вывода списка активных сред. Синхронизация вызывает скрипт перед генерацией.

## Аргументы

| Аргумент | Значение |
|---|---|
| `--root` | Корень проекта. По умолчанию текущий каталог. |
| `--enabled` | Проверить указанный ID среды. |
| `--list-enabled` | Вывести массив активных ID в JSON. |
| `--list-enabled-shell` | Вывести активные ID через пробел. |

## Коды выхода

`0` - успех. `1` - среда не включена. `2` - ошибка аргументов или реестра.

## Что читает и что пишет

Читает `harness-core/assets/environments.json` из своей установки и целевого проекта. Пишет только в stdout и stderr.

## Побочные эффекты

Файлы не меняет.

## Окружение и зависимости

Python 3, стандартная библиотека.

## Примеры

```bash
python3 .agents/skills/harness-router/children/environment-sync/scripts/environment_policy.py --root . --list-enabled
```

## Ограничения

Целевой проект может переключать только известные текущей установке среды.
