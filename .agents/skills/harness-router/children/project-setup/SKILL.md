# project-setup

## Когда применять

- Когда нужен сценарий project-setup в управлении харнесом.

## Вход

- Корень проекта и конфиги `harness-router`.

## Шаги

1. Прочитать конфиги сред и kit.
2. Выполнить сценарий через `harness_cli.py`.
3. Проверить отчет.

## Выход

- Результат сценария и отчет.

## Ограничения

- Не дублировать код родителя.
- Не хранить состояние в скиле.
