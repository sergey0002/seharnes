# mcp-audit

Назначение.
Проверяет состав MCP-серверов, их документацию, правила вызова и формат хранения
данных.

Как работает.
Сверяет конфиг с документами и правилами, проверяет строки в картах и каталог
данных каждого сервера. Отдельно проверяет, что в документах нет значений
секретов. Запускает smoke-проверку серверов и проверку представлений. Дополнительно `harness_mirror.py visibility --summary` проверяет, что MCP-правила доступны в средах, а гейты подключаются inline.

Что нужно.
Корень проекта, конфиг MCP, правила MCP, документы серверов и состояние проекта.
Для smoke-проверки нужен доступ к запуску серверов.

Чего не делает.
Не добавляет сервер вместо component-install, не печатает секреты, не правит
клиентские конфиги вручную и не хранит данные сервера в папке скила.
