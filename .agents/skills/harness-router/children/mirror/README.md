# mirror

Назначение.
Увидеть харнес как граф: из каких файлов он состоит, что на что ссылается, где
дубли, расхождения между каноном и зеркалами, а также режим видимости каждого правила в среде.

Как работает.
Скрипт детерминированно раскладывает каждый файл на блоки, считает хеши и
собирает структуру. При склейке блоков файл возвращается байт в байт. Смысл,
жизненный цикл и связи дописывает агент. Результат смотрится в статической
панели. Команда `visibility` дополнительно строит проверяемую матрицу инжекта правил
для сред, правка разрешена только для канона скилов и правил.

Что нужно.
Python без внешних библиотек, канон харнеса и каталог данных для узлов и графа.

Чего не делает.
Не индексирует документацию, задачи и код продукта, не правит зеркала и не
заменяет синхронизацию сред.
