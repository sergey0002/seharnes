# remove-skill

Назначение.
Удаляет скил из харнеса так, чтобы не остались копии в средах, битые ссылки и
устаревшие записи документации.

Как работает.
Скил находит скил в каноне и зеркалах, собирает упоминания, делает бэкап,
удаляет каталоги, карточку, строки индексов и запись реестра. Родительский
роутер пересобирается, затем запускаются синхронизация и проверки.

Что нужно.
Корень проекта, Python 3, доступ к канону и скриптам синхронизации. Для
неинтерактивного запуска нужен флаг --yes.

Чего не делает.
Не удаляет MCP-серверы и не переписывает текст правил и документации без
решения человека. Такие ссылки скил показывает отдельным списком.
