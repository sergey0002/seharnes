# index

Назначение.
Дать картину по скилу или правилу без чтения всего файла: что делает, с чем
связано, на какой фразе основана связь и какие пробелы есть.

Как работает.
Скил это инструкция, а не код. Он задает маршруты по командам инструмента
зеркала харнеса: дайджест для одного элемента, обзор скила, полный текст узла,
список кандидатов на смысловую проверку и запись смысла обратно в индекс.

Что нужно.
Построенный индекс харнеса и доступ к его каталогу данных.

Чего не делает.
Не заменяет правила проекта, не запускает продуктовые проверки и не индексирует
документацию, задачи или код продукта.
