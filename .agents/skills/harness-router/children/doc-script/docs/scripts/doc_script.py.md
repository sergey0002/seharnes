## Суть
Находит запускаемые скрипты харнеса, извлекает аргументы, коды выхода, окружение и
побочные эффекты, создает документ в скиле-владельце и проверяет его. Документация
лежит в `{skill}/docs/scripts/{файл скрипта}.md`.

## Когда запускать
Запускать при добавлении или изменении скрипта, а также в гейте `docs-scripts`
команды `harness doctor`. Без запуска новый скрипт остается без документа, и агент
вынужден читать исходник перед вызовом.

## Аргументы
| Аргумент | Алиас | Тип | Обязателен | По умолчанию | Что делает |
|---|---|---|---|---|---|
| `--script` | нет | путь | нет | нет | создать документ для одного скрипта; вместе с `--audit` проверить только его |
| `--force` | `-f`, `--overwrite` | флаг | нет | выключен | принудительно перезаписать существующий документ |
| `--list` | нет | флаг | нет | выключен | показать все запускаемые скрипты и пути документов |
| `--all` | нет | флаг | нет | выключен | создать скелеты для скриптов без документа |
| `--audit` | нет | флаг | нет | выключен | проверить документы всех скриптов |
| `--policy-root` | нет | путь | нет | не задан | при аудите добавить обязательные разделы из политики проекта без снятия встроенных проверок |
| `--inventory` | нет | флаг | нет | выключен | показать классификацию скриптов по категориям |

## Коды выхода
| Код | Значение | Действие вызывающего |
|---|---|---|
| 0 | документ создан, проверка прошла или показана справка `--help` | продолжить |
| 1 | скрипт не найден, нет владельца, документ существует без `--force`, обнаружены коллизии, попытка выхода за пределы скила или аудит нашел ошибки | исправить и повторить |
| 2 | неверные аргументы командной строки | передать корректные аргументы |

## Что читает и что пишет
Читает `.tools/scripts/*`, `.cursor/mcp-stack/*`, `.agents/skills/**/scripts/*`, `.dsh/scripts/*` и `.dsh/skills/**/scripts/*`. Пишет `{skill}/docs/scripts/{файл скрипта}.md`, для `.tools/scripts` пишет `harness-core/docs/scripts/tools/{файл скрипта}.md`. В stdout печатает путь документа или список скриптов, ошибки аудита идут в stderr.

## Побочные эффекты
Атомарно создает и перезаписывает файлы документов через временный файл и замену (replace).
Проверяет границы каталога владельца и блокирует выход через симлинки.
Маскирует значения конфиденциальных параметров (`token`, `secret`, `password`, `key`).
Не делает сетевых запросов, не пишет в базу, не меняет git, не запускает контейнеры.

## Окружение и зависимости
Переменных окружения не требуется. Нужен Python 3.8+ и стандартная библиотека.
Для Python 3.8 предусмотрен встроенный разбор узлов AST вместо ast.unparse.
Запускается из корня проекта.

## Примеры
```bash
python3 .agents/skills/harness-router/children/doc-script/scripts/doc_script.py --list
python3 .agents/skills/harness-router/children/doc-script/scripts/doc_script.py \
  --script .tools/scripts/multi-search.sh
python3 .agents/skills/harness-router/children/doc-script/scripts/doc_script.py --audit
```

## Ограничения
Разбор аргументов эвристический: `getopts`, `case`, `param(...)`, `argparse`,
`option()` и Symfony Console. Сложные самописные парсеры распознаются частично.
Семантику разделов `Суть`, `Когда запускать`, `Ограничения` и `Связи` заполняет
агент, скрипт дает только скелет. Библиотеки без точки входа не документируются.
