# add-skill

Назначение.
Устанавливает локальный скил в канон харнеса и приводит его документацию к
правилам проекта.

Как работает.
Скил сканирует канон и зеркала сред, находит скилы вне манифеста пакета,
проверяет структуру, копирует выбранный скил в канон, создает недостающие
README и skill.json, обновляет реестр и родительский
роутер. Затем запускает синхронизацию сред, visibility-проверку правил и валидаторы. При переносе правил учитывает `gate: true` и `attach: glob`. Данные компонента
хранятся в отдельном каталоге проекта, не в папке скила.

Что нужно.
Корень проекта, Python 3, доступ к канону и скриптам синхронизации. Для
неинтерактивного запуска нужен флаг --yes.

Чего не делает.
Не выбирает версию при конфликте, не создает документы скриптов автоматически и не
перезаписывает существующий канон без разрешения. Не добавляет MCP вместо
component-install и не считает скил установленным без документации и отдельного
места хранения данных.
