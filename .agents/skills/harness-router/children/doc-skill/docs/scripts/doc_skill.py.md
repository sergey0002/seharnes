## Суть
Проверяет README каждого скила: наличие файла, отсутствие ссылок
и раздела `Связи`, отсутствие заглушек. Документация скила это его README, отдельной
карточки нет.

## Когда запускать
Запускать при создании или изменении скила, а также в гейте `docs-skills` команды
`harness doctor`. Без запуска README может остаться черновиком или разрастись до
пересказа `SKILL.md`.

## Аргументы
| Аргумент | Алиас | Тип | Обязателен | По умолчанию | Что делает |
|---|---|---|---|---|---|
| `--skill` | нет | путь | нет | нет | проверить README одного скила |
| `--list` | нет | флаг | нет | выключен | показать все скилы и наличие README |
| `--audit` | нет | флаг | нет | выключен | проверить README всех скилов |
| `--policy-root` | нет | путь | нет | не задан | добавить к аудиту запрещённые шаблоны из YAML-политики проекта |

## Коды выхода
| Код | Значение | Действие вызывающего |
|---|---|---|
| 0 | все README прошли проверку | продолжить |
| 1 | найдены ошибки или указанный путь не скил | исправить README и повторить |
| 2 | неверные аргументы или запрошена справка | передать корректные аргументы |

## Что читает и что пишет
Читает `.agents/skills/**/SKILL.md` для поиска скилов и `README.md` для проверки.
Ничего не пишет. В stdout печатает список или итог, ошибки идут в stderr.

## Побочные эффекты
Побочных эффектов нет. Файлы не меняются, сеть, база и git не затрагиваются.

## Окружение и зависимости
Переменных окружения не требуется. Нужен Python 3.8+ и стандартная библиотека.

## Примеры
```bash
python3 .agents/skills/harness-router/children/doc-skill/scripts/doc_skill.py --list
python3 .agents/skills/harness-router/children/doc-skill/scripts/doc_skill.py \
  --skill .agents/skills/harness-router/children/mirror
python3 .agents/skills/harness-router/children/doc-skill/scripts/doc_skill.py --audit
```

## Ограничения
Проверка структурная: длина, ссылки, раздел `Связи`, заглушки. Смысловое качество
README скрипт не оценивает, это делает агент по скилу `doc-skill`. Скилы ищутся по
наличию `SKILL.md`, папка `docs` исключена.
