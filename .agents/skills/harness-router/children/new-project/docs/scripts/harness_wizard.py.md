## Суть

Собирает ответы мастера и вызывает `harness_transfer.py plan`. Мастер задаёт три независимых вопроса: источник kit, операция и Target. Файлы он не копирует и конфликты не разрешает.

## Когда запускать

Для пошагового выбора источника, профиля и Target перед предпросмотром обновления. Для автоматизации использовать `--non-interactive` и явные флаги.

## Аргументы

| Аргумент | Значение |
|---|---|
| `--source-kind` | `local` или `git`. |
| `--source` | Каталог локального исходника. |
| `--repo` | Локальное bare-хранилище Git. |
| `--commit` | Полный commit SHA. |
| `--target` | Каталог проекта. |
| `--profile` | `core`, `developer` или `project`. |
| `--operation` | `install` или `update`. |
| `--root` | Корень выбора файлов; повторяется. |
| `--path` | Явный путь; повторяется. |
| `--base-commit` | Исторический commit для сравнения. |
| `--release-manifest` | Производный манифест релиза для сверки выбранных файлов. |
| `--use-receipt` | Прочитать receipt Target. |
| `--local` | Путь, принадлежащий Target; повторяется. |
| `--use-local-policy` | Прочитать `canon-paths.local.yaml`. |
| `--max-file-bytes` | Предел размера файла. |
| `--non-interactive` | Не задавать вопросов; обязательные значения передаются флагами. |
| `--yes` | Не спрашивать подтверждение перед предпросмотром. |

## Коды выхода

`0` - предпросмотр построен или мастер отменён; `2` - предпросмотр требует решений; `3` - не хватает обязательного выбора или ввод недоступен.

## Что читает и что пишет

Пишет только временное состояние предпросмотра через `harness_transfer.py`. Управляемые файлы, `.git` и receipt не меняет.

## Побочные эффекты

В интерактивном режиме читает stdin и печатает вопросы. В неинтерактивном режиме вопросов не задаёт.

## Окружение и зависимости

Python 3. Использует `harness_transfer.py` в каталоге скриптов.

## Примеры

```sh
python3 .agents/skills/harness-router/children/new-project/scripts/harness_wizard.py \
  --non-interactive --source-kind git --repo /tmp/seharnes.git --commit FULL_COMMIT_ID \
  --target /tmp/project --root .agents/skills --profile core --operation update
```

## Ограничения

Мастер не применяет план и не разрешает конфликты. `apply/rollback` ещё не реализованы, поэтому результат всегда предпросмотр. Значения секретов мастер не запрашивает и не печатает.

## Связи

Вызывает `harness_transfer.py`. Описан в `SKILL.md` как вход для предпросмотра, не как механизм применения.
