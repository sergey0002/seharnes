## Суть

Собирает производный `harness-release-manifest` из одного Git commit: путь, режим, размер и SHA-256 каждого отслеживаемого blob. Манифест не является авторским списком состава и не заменяет канон путей.

## Когда запускать

Перед публикацией релизного репозитория и для сверки поставленного дерева с закреплённым commit.

## Аргументы

| Аргумент | Значение |
|---|---|
| `--root` | Корень Git working tree, не вложенный каталог. |
| `--commit` | Ревизия, которая разрешается в commit; по умолчанию `HEAD`. |
| `--out` | Записать манифест в файл; без флага JSON идёт в stdout. |
| `--json` | Принимается для общего контракта; вывод всегда JSON. |
| `--max-file-bytes` | Предел размера blob, по умолчанию 8 МиБ; больший файл попадает в `excluded`. |

## Коды выхода

`0` - манифест построен; `2` - ошибка Git, политики, пути или ревизии.

## Что читает и что пишет

Читает tracked blob, дерево Git и три policy-файла через `git cat-file` и `git ls-tree`. Пишет только `--out`; checkout, hooks, filters и код кандидата не запускаются.

## Побочные эффекты

Запускает локальный Git для чтения объектов. Временный каталог с policy-файлами создаётся только для проверки bundle и удаляется после завершения.

## Окружение и зависимости

Python 3 и Git в PATH. Использует `canon_paths.py` и правила защищённых имён `transfer_inventory.py`.

## Примеры

```sh
python3 .agents/skills/harness-router/children/new-project/scripts/release_manifest.py \
  --root /home/user/seharnes --commit HEAD --out /tmp/harness-release.json
```

## Ограничения

Манифест перечисляет все tracked blob, кроме защищённых путей и файлов сверх лимита. Он не выбирает состав профиля Core/Developer/Project, не проверяет лицензии, качество содержимого и не доказывает доверие к commit. Символические ссылки, submodule и специальные записи останавливают построение. `excluded` виден в отчёте и не удаляется из Git.

## Связи

Используется при подготовке релиза `seharnes` и сверке с receipt. Опирается на `canon_paths.py` и `transfer_inventory.py`.
