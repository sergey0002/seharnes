## Суть

Проверяет, видит ли Git несколько обязательных файлов в рабочем дереве будущего репозитория харнеса.

## Когда запускать

До подготовки содержимого отдельного Git-репозитория харнеса.

## Аргументы

| Аргумент | Значение |
|---|---|
| `--root` | Корень Git working tree, не вложенный каталог. |

## Коды выхода

`0` — все проверенные файлы видимы; `1` — файл отсутствует или исключён Git; `2` — ошибка запуска или Git.

## Что читает и что пишет

Читает правила ignore обычной Git-конфигурации и наличие фиксированного списка файлов. Записывает JSON в stdout; файлы, индекс и настройки не меняет.

## Побочные эффекты

Запускает локальный Git `rev-parse` и `check-ignore`. Сеть не используется.

## Окружение и зависимости

Python 3 и Git в PATH; использует локальную библиотеку `transfer_plan.py`.

## Примеры

```sh
python3 .agents/skills/harness-router/children/new-project/scripts/release-repo-check.py --root /path/to/seharnes
```

## Ограничения

Проверяется только фиксированный набор контрольных путей, а не вся поставка. Даже при коде 0 секреты, состав профилей, настройки remote и возможность публикации не проверены: `release_safe` всегда false. Скрипт не снимает исключения автоматически.

## Связи

Диагностика для подготовки отдельного репозитория харнеса; не вызывается автоматически при переносе в обычный проект.
