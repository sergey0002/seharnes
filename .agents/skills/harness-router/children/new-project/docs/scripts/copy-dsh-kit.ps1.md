## Суть
Синхронизирует DSH kit из Source в Target: каталоги `skills/`, `adapters/`, `scripts/`, `tests/` и файлы `models.overlay.json`, `kit.manifest.json`. Управляемые каталоги заменяются целиком, лишние локальные файлы в них удаляются. Остальные файлы `.dsh/`, включая `project.patch.yml`, не затрагиваются; `DSH-RULES.md` не копируется. `-Check` сравнивает пути и SHA-256 содержимого без записи.

## Когда запускать
- При переносе харнеса в новый проект (`rebase_project.ps1` вызывает внутри).
- При обновлении DSH kit в существующем проекте (`update` mode).
- Агент/пользователь запускает вручную для синхронизации `.dsh/`.

## Аргументы
| Аргумент | Алиас | Тип | Обязателен | По умолчанию | Что делает |
|---|---|---|---|---|---|
| -Source |  | string | да |  | Корень проекта-образца |
| -Target |  | string | да |  | Корень нового проекта |
| -Check |  | switch | нет |  | Проверить состав и содержимое kit без записи |
| -PreserveLocal |  | switch | нет | false | Сохранить файлы Target, отсутствующие в Source; файлы с совпадающим путём заменяются |

## Коды выхода
| Код | Значение | Действие вызывающего |
|---|---|---|
| 0 | Успех (kit скопирован или проверка пройдена) | Продолжить работу |
| 1 | Состав или содержимое отличается, либо произошла ошибка PowerShell | Проверить диагностику и повторить копирование |
| 2 | Source `.dsh` не найден | Проверить путь Source |

## Что читает и что пишет
**Читает:**
- `$Source/.dsh/` — kit каталоги: skills, adapters, scripts, tests + models.overlay.json, kit.manifest.json
- `$Source/.dsh/kit.manifest.json` - список файлов, наличие которых проверяется до записи.

**Пишет:**
- `$Target/.dsh/` - замена управляемых каталогов и двух файлов kit.
- `__pycache__` и `.pytest_cache` из Source не копируются, такие файлы в Target считаются лишними.

## Побочные эффекты
- Создаёт/обновляет `$Target/.dsh/`.
- Без `-PreserveLocal` удаляет файлы Target внутри управляемых каталогов, отсутствующие в Source. С `-PreserveLocal` сохраняет их, но заменяет файлы с совпадающим путём. До запуска сохраните нужные локальные изменения.
- Проверка выполняется после копирования. Ошибка при записи может оставить Target частично обновлённым; автоматического отката нет.

## Окружение и зависимости
- PowerShell 5+ / pwsh.
- Использует команды файловой системы PowerShell и `Get-FileHash`.
- Не требует git, docker, сети.

## Примеры
```powershell
# Копировать kit из текущего проекта в новый
pwsh -NoProfile -File .agents/skills/harness-router/children/new-project/scripts/copy-dsh-kit.ps1 -Source . -Target ..\newproject

# Проверить полноту kit на Target (без записи)
pwsh -NoProfile -File .agents/skills/harness-router/children/new-project/scripts/copy-dsh-kit.ps1 -Source . -Target ..\newproject -Check
```

Вывод при расхождении указывает `missing`, `extra` или `changed` и относительный путь.

## Ограничения
- Все четыре каталога, оба файла kit и файлы из манифеста обязательны в Source. Отсутствие останавливает операцию до изменения Target.
- Совпадающие или вложенные Source и Target запрещены. Символьные ссылки в корнях, их предках и управляемых путях запрещены.
- Сверка проверяет файлы и обязательные корневые каталоги kit. Пустые вложенные каталоги не сравниваются.
- `rebase_project.ps1` останавливается при ошибке копирования, проверки или отсутствии helper; предшествующие этапы rebase не откатываются.

## Связи
- Вызывается: `rebase_project.ps1` (внутри), агент вручную, `new-project` скил
- Зависит от: структуры `.dsh/` в Source
- Результат используется: Target проект получает DSH kit для синхронизации view

## Изменения 2026-11-12

Перенос блокируется при пересечении корней. Для migrate/update DSH вызывается с `-PreserveLocal`: target-only файлы не удаляются; самостоятельный вызов без флага сохраняет строгий mirror-контракт. Discovery-указатели DSH не копируются из Source, их создаёт sync. Манифест бэкапа охватывает изменяемые каталоги, включая .tools и документацию; локальные адаптеры Source исключены из копирования.

Full включает .doc/harnes целиком, QA и web без секретов; skil_data только примеры. Core оставляет операционные скилы кода и внутренние адаптеры, исключая authoring/task/Jira, панель и документацию разработки. Финальный sync --local-only выполняется после выбора профиля и merge канона. AGENTS.md существующего проекта и настройки Codex не заменяются шаблоном. Source leaf не подставляется глобально в исходники; меняются только абсолютные пути.
