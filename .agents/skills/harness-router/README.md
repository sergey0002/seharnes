# harness-router

Назначение.
Маршрутизирует запросы по харнесу к дочерним скилам.

Как работает.
Роутер читает запрос, выбирает дочерний скил по таблице и передает управление.

Что нужно.
Корень проекта и дочерние скилы харнеса.

Чего не делает.
Не содержит скриптов, данных и содержательных инструкций.
