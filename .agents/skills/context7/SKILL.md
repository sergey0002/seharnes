# context7

## Когда применять

Когда нужен ответ по внешней зависимости, подтвержденный документацией ее версии.
Внутреннюю документацию проекта ищет `jdocmunch`.

## Шаги

1. Определи библиотеку и версию по `composer.json`, `package.json` или постановке.
2. Вызови `resolve-library-id` с `libraryName` и конкретным `query`.
3. Возьми возвращенный `libraryId`. Если пользователь уже указал точный ID,
   используй его без повторного разрешения.
4. Вызови `query-docs` с `libraryId` и вопросом о нужном API и версии.
5. Сверь пример с установленной версией. Укажи источник и неподтвержденные различия.

## Границы

- Не отправляй секреты, персональные данные и приватный код во внешний сервис.
- Не используй Context7 для бизнес-логики проекта, рефакторинга или code review.
- Пустой ответ не подтверждает отсутствие API. Зафиксируй ограничение источника.
