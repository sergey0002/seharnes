## Суть

Документация внешних библиотек, фреймворков, SDK и облачных API по актуальной версии. Первый источник для вопросов о чужом API, вместо памяти модели.

---


## Когда вызывать

Когда брать сервер и в каком порядке: правило `.cursor/rules/mcp/context7.mdc`, раздел `Когда`. Здесь фиксируется только эксплуатационное условие: сервер берут, когда локальный файл или тест не дают ответ дешевле.

## Конфигурация

| Параметр | Значение |
|---|---|
| Тип | stdio |
| Запуск | `npx -y @upstash/context7-mcp@3.2.2` |
| Сеть | нужен доступ к Context7 |

---


## Текущие значения

| Параметр | Значение |
|---|---|
| Статус | включен |
| Транспорт | `command: npx -y @upstash/context7-mcp@3.2.2` |
| Переменные окружения | нет |

Секреты не печатаются, только имена переменных. Полная конфигурация в разделе `Конфигурация`.

## Инструменты

| Инструмент | Параметры | Зачем |
|---|---|---|
| `resolve-library-id` | `query`, `libraryName` | идентификатор библиотеки по имени |
| `query-docs` | `libraryId`, `query` | документация по версии |

`libraryId` имеет вид `/org/project` или `/org/project/version`.

---

## Правила использования

1. Использовать для библиотек, фреймворков, SDK, API, CLI и облачных сервисов, включая известные.
2. Не использовать для рефакторинга, бизнес-логики, code review и общих концепций.
3. В запрос не передавать секреты и приватный код.

---

## Установка и перенос

- Установка: Node и `npx -y @upstash/context7-mcp@3.2.2`; отдельный каталог не нужен.
- Перенос: скопировать запись `context7` из `.cursor/mcp.json`; версия закреплена, локальных файлов нет.
- Проверка: `node .agents/skills/harness-router/children/mcp-audit/scripts/test-mcp-servers.mjs --only=context7`.

## Несколько проектов

- stdio-сервер запускается клиентом на каждый проект отдельно, состояние не общее.
- Конфиг проекта побеждает глобальный; секретов и кеша на диске нет.
- Версию библиотеки брать из `composer.json` или `package.json` проекта, не из глобального окружения.

## Известные проблемы и ограничения

- Симптом: библиотека не находится.
  Причина: неверное имя или нет сети.
  Решение: уточнить официальное имя, повторить `resolve-library-id`.
