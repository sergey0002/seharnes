# codeprism

Назначение.
Дает агенту структурный контекст по коду до чтения файлов: символы, вызывающих,
вызываемых, влияние правки, зависимости, поток данных и проверку безопасности
перед записью.

Как работает.
Агент сначала запрашивает статистику графа и контекст символа, затем при
необходимости уточняет вызывающих, зависимости и влияние. Перед правкой
прогоняет проверку предложенного текста и при критической находке отказывается
от записи. На длинных задачах ведет учет прочитанного и записанного, умеет
откатывать свои записи.

Что нужно.
Пакет codeprism-ai версии 0.1.11 в локальном окружении проекта, настроенный
MCP-сервер codeprism и построенный индекс проекта. Индекс хранится вне
репозитория, по одному файлу на проект.

Чего не делает.
Не отдает полные тела функций, не заменяет чтение файла. Не индексирует
Smarty-шаблоны, Markdown и файлы из игнора git. Не связывает вызовы через
импорты ни для одного языка, кроме Python, поэтому одноименные функции могут
связываться неверно. Не заменяет codegraph для точного исходника и Serena для
правок PHP.
